# FileUploader

## Директива `meFileUploader`

Директива `meFileUploader` стилизует компонент `dx-file-uploader` в соответствии с требованиями дизайн-системы и добавляет свойство `size` со значением `size="medium"` по умолчанию.

### Базовое использование (AsyncUploadInstantly)

Загрузка одного файла с немедленным началом загрузки.

### Кастомная дроп-зона

Создание кастомной дроп-зоны позволяет настроить внешний вид области перетаскивания файлов, добавить индикатор прогресса и предварительный просмотр загруженных изображений. В примере ниже зона определяется кастомным HTML-контентом, а события загрузки обрабатываются для обновления интерфейса.

<Canvas name="AdvancedCustomDropZone" of={fileUploaderDirectiveStories.AdvancedCustomDropZone} />

<Source
  code={`
<div class="widget-container flex-box">
  <span>Profile Picture</span>
  <div
    id="dropzone-external"
    class="flex-box"
    [ngClass]="isDropZoneActive ? 'dropzone-active' : null">
    <img id="dropzone-image" [src]="imageSource" *ngIf="imageSource" alt="" />
    <div id="dropzone-text" class="flex-box" *ngIf="textVisible">
      <span>Drag & Drop the desired file</span>
      <span>…or click to browse for a file instead.</span>
    </div>
    <dx-progress-bar
      meProgressBar
      #uploadProgress
      [min]="0"
      [max]="100"
      width="30%"
      [showStatus]="false"
      [visible]="progressVisible"
      [value]="progressValue">
    </dx-progress-bar>
  </div>
  <dx-file-uploader
    dialogTrigger="#dropzone-external"
    dropZone="#dropzone-external"
    meFileUploader
    [multiple]="false"
    [allowedFileExtensions]="allowedFileExtensions"
    uploadMode="instantly"
    uploadUrl="https://js.devexpress.com/Demos/NetCore/FileUploader/Upload"
    [visible]="false"
    (onDropZoneEnter)="onDropZoneEnter($event)"
    (onDropZoneLeave)="onDropZoneLeave($event)"
    (onUploaded)="onUploaded($event)"
    (onProgress)="onProgress($event)"
    (onUploadStarted)="onUploadStarted()">
  </dx-file-uploader>
</div>
  `}
  dark
  language="html"
/>

### Обработка событий

Пример демонстрирует обработку событий загрузки файлов, таких как начало загрузки, прогресс, успешная загрузка и ошибка.

<Source
  code={`
<dx-file-uploader
  meFileUploader
  (onUploadStarted)="onUploadStarted($event)"
  (onUploaded)="onUploaded($event)"
  (onProgress)="onProgress($event)"
  (onUploadError)="onUploadError($event)">
</dx-file-uploader>

// В компоненте:
onUploadStarted(e) {
  console.log('Upload started:', e);
}

onUploaded(e) {
  console.log('File uploaded:', e);
}

onProgress(e) {
  const progress = (e.bytesLoaded / e.bytesTotal) * 100;
  console.log('Upload progress:', progress);
}

onUploadError(e) {
  console.error('Upload error:', e);
}
  `}
  dark
  language="typescript"
/>
