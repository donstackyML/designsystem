# FileUploader

## Компонент `me-file-uploader`

Компонент `me-file-uploader` предоставляет расширенную функциональность для загрузки файлов. Он поддерживает проверку типов файлов, ограничение по размеру, возможность множественной загрузки и настраиваемые тексты для метки и кнопки выбора. Используйте данный компонент для создания удобного и информативного интерфейса загрузки файлов, который соответствует требованиям вашей дизайн-системы.

### Загрузка одного файла

Для загрузки одного файла установите параметр `multiple` в значение `false`.

<Canvas name="Загрузка одного файла" of={fileUploaderComponentStories.SingleFileUpload} />
<Source
  code={`<me-file-uploader [multiple]="false" labelText="Выберите один файл"></me-file-uploader>`}
  dark
  language="html"
/>

### Пользовательские типы файлов

Ограничьте загрузку только документами, например, с расширениями `jpg`, `png`, `pdf`.

<Canvas name="Пользовательские типы файлов" of={fileUploaderComponentStories.WithFileExtensionRestriction} />
<Source
  code={`
<me-file-uploader
  [allowedFileExtensions]="['jpg', 'png', 'pdf']"
  labelText="Выберите файлы только с расширениями JPG, PNG или PDF">
</me-file-uploader>`}
  dark
  language="html"
/>

Если вы не хотите отображать список выбранных файлов, установите параметр `showFileList` в значение `false`.

### Загрузка файлов с пользовательским интерфейсом

Настройте загрузчик файлов с индивидуальными сообщениями, ограничениями по размерам, типами файлов и поддержкой множественной загрузки для создания удобного интерфейса.

<Canvas name="Загрузка файлов с пользовательским интерфейсом" of={fileUploaderComponentStories.CustomizableUploader} />
<Source
  code={`
<me-file-uploader
  labelText="Перетащите ваши файлы сюда или нажмите кнопку ниже"
  selectButtonText="Выбрать файлы"
  [allowedFileExtensions]="['jpg', 'png', 'pdf']"
  [maxFileSize]="5 * 1024 * 1024"
  [multiple]="true"
></me-file-uploader>
`}
  dark
  language="html"
/>

### Обработка событий

Компонент `me-file-uploader` поддерживает события для управления процессом загрузки. Например, вы можете реагировать на добавление, удаление или неудачную попытку загрузки файла.

<Source
  code={`
<me-file-uploader
  (fileAdded)="onFileAdded($event)"
  (fileRemoved)="onFileRemoved($event)"
  (allFilesRemoved)="onAllFilesRemoved()"
  (invalidFile)="onInvalidFile($event)"
></me-file-uploader>

// В вашем компоненте:
onFileAdded(file: File) {
  console.log('Файл добавлен:', file);
}

onFileRemoved(file: File) {
  console.log('Файл удален:', file);
}

onAllFilesRemoved() {
  console.log('Все файлы удалены');
}

onInvalidFile(event: { file: File; error: string }) {
  console.log('Недопустимый файл:', event);
}
`}
  dark
  language="typescript"
/>
