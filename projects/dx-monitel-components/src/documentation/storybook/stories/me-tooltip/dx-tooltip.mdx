# DxTooltipComponent

Компонент `DxTooltipComponent` от DevExtreme позволяет создавать кастомные всплывающие подсказки с широкими возможностями настройки внешнего вида, анимации, позиционирования и поведения. Он идеально подходит для информативных UI-подсказок, обогащая пользовательский опыт.

<Controls of={dxTooltipStories.Default} />

## Основные возможности

- **Позиционирование:** можно указать направление появления (`top`, `bottom`, `left`, `right`) или использовать объект конфигурации `PositionConfig`.
- **Размеры:** кастомная ширина, высота, а также ограничения по максимальной ширине и высоте.
- **События показа/скрытия:** настройка триггеров (`mouseenter`, `click`, `focus` и т.д.).
- **Анимация:** полная настройка анимации для появления и исчезновения.
- **tooltipId**: `string`. уникальный идентификатор, к которому будет привязан тултип.
- **Контент:** можно передавать любой HTML, включая текст, изображения и кастомные шаблоны.

### Размеры тултипа

У компонента `DxTooltipComponent` **нет встроенного свойства `size`**.  
Для управления размерами используется механизм `wrapperAttr`, в который можно передать собственный CSS-класс. 

В Storybook параметр `size` (`small`, `medium`, `large`) служит удобной абстракцией: он автоматически формирует значение для `wrapperAttr` и подставляет соответствующий класс (`me-tooltip-small`, `me-tooltip-medium`, `me-tooltip-large`).  
В реальном проекте эти классы нужно добавить вручную или использовать директиву.
