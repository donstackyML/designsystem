# TreeView

## Директива `meTreeView`

Применение директивы `meTreeView` к элементу `dx-tree-view` приводит его внешний вид в соответствие с дизайн-системой, его размеры к значению `size = large` (*24px*) и предоставляет доступ к свойству `size`.

Добавление нетипичных для DevExtreme элементов производится через переопределение свойств [`itemTemplate`](https://js.devexpress.com/Angular/Documentation/ApiReference/UI*Components/dxTreeView/Configuration/#itemTemplate).

### Настройка структуры данных

*TreeView ожидает иерархическую структуру данных, где каждый элемент должен иметь уникальный идентификатор, текст и, при наличии подпунктов, массив `items`. Это позволяет создавать сложные и многоуровневые деревья.*

<Source
  code={`
const hierarchicalData = [{
  id: '1',
  text: 'Fruits',
  items: [
    { id: '1*1', text: 'Apples' },
    { id: '1*2', text: 'Oranges' }
  ]
}, {
  id: '2',
  text: 'Vegetables',
  items: [
    { id: '2*1', text: 'Cucumbers' },
    { id: '2*2', text: 'Tomatoes' }
  ]
}];
  `}
  dark
  language="js"
/>

### Настройка поведения текста

*Свойство `textTruncateBehavior` позволяет задать, как будет отображаться длинный текст элементов дерева. При значении `truncate` текст обрезается с добавлением многоточия, а при значении `wrap` — переносится на новую строку.*

#### Текст с обрезкой

<Canvas name="Текст с обрезкой" of={treeViewStories.TextOverflowBehaviorTruncateWithTooltip} />

<Source
  code={`
<tree-view
  meTreeView
  [dataSource]="dataSource"
  [textTruncateBehavior]="'truncate'">
</tree-view>
  `}
  dark
  language="html"
/>

#### Текст с переносом

<Canvas name="Текст с переносом" of={treeViewStories.TextOverflowBehaviorWrap} />

<Source
  code={`
<tree-view
  meTreeView
  [dataSource]="dataSource"
  [textTruncateBehavior]="'wrap'">
</tree-view>
  `}
  dark
  language="html"
/>

### Режимы выбора элементов

*Свойство `selectionMode` определяет, как пользователь может выбирать элементы в дереве. В примерах показаны режимы одиночного (`single`) и множественного (`multiple`) выбора.*

#### Одиночный выбор

<Canvas name="Одиночный выбор" of={treeViewStories.SelectionModeSingle} />

<Source
  code={`

  meTreeView
  [dataSource]="dataSource"

</tree-view>
  `}
  dark
  language="html"
/>

#### Множественный выбор

<Canvas name="Множественный выбор" of={treeViewStories.SelectionModeMultiple} />

### Поиск в дереве

*Свойство `searchEnabled` включает возможность поиска по элементам дерева, позволяя пользователю фильтровать данные по введённому запросу.*

<Canvas name="Поиск в дереве" of={treeViewStories.WithSearch} />

<Source
  code={`
<tree-view
  meTreeView
  [dataSource]="dataSource"
  [searchEnabled]="true">
</tree-view>
  `}
  dark
  language="html"
/>

### Отключение компонента

*Свойство `disabled` позволяет сделать дерево неинтерактивным. В этом режиме пользователь не может выбрать или раскрыть элементы дерева.*

<Canvas name="Отключённое дерево" of={treeViewStories.DisabledState} />

<Source
  code={`
<tree-view
  meTreeView
  [dataSource]="dataSource"
  [disabled]="true">
</tree-view>
  `}
  dark
  language="html"
/>

### Фиксированная высота дерева

*Задание фиксированной высоты с помощью свойства `height` ограничивает область отображения дерева и может добавить скролл, если элементов много.*
