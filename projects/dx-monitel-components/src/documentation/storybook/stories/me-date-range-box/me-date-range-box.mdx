# DateRangeBox

## Директива `meDateRangeBox`

Применение директивы `meDateRangeBox` к элементу `dx-date-range-box` приводит его размеры к значению `size=medium` из дизайн-системы, а также приводит отступы в соответствие с дизайн-системой, добавляет свойство `size` и стилизует календарь.

### Изменение положения лейбла с помощью директивы meLabel

Для вывода лейбла вне текстового поля можно использовать директиву `meLabel`. Это позволяет разместить метку отдельно от самого поля, задавая её положение с помощью свойства `labelDirection`.

#### Положение лейбла сверху

Чтобы лейбл располагался над текстовым полем, оберните компонент в контейнер с директивой `meLabel` и установите `labelDirection="column"`. Это позволяет создать вертикальное расположение, где метка находится сверху, а само поле — под ней.

<Canvas name="Лейбл сверху" of={dateRangeBoxStories.WithLabelColumn} />

<Source
  code={`
<div meLabel labelDirection="column">
  <span>Label</span>
  <dx-date-range-box meDateRangeBox labelMode="hidden"></dx-date-range-box>
</div>
`}
  language="html"
  dark
/>

#### Положение лейбла слева

Чтобы разместить лейбл слева от текстового поля, используйте `labelDirection="row"`. Для корректного выравнивания задайте фиксированную ширину контейнера, например, через атрибут `width`.

<Canvas name="Лейбл слева" of={dateRangeBoxStories.WithLabelRow} />

<Source
  code={`
<div meLabel labelDirection="row"  class="dx-widget">
  <span>Label</span>
  <dx-date-range-box meDateRangeBox labelMode="hidden"></dx-date-range-box>
</div>
`}
  language="html"
  dark
/>

### Валидация поля

Для валидации используйте `<dx-validator>` внутри компонента `dx-date-range-box`. Для добавления валидации используйте тэг `<dxi-validation-rule>` и параметры `type` и `message`.
Не забудьте импортировать `DxTextAreaModule` и `DxValidatorModule`.
Используйте параметры `validationMessageMode` для изменения режима отображения сообщения об ошибке. Варианты: `auto` и `always`.
Используйте параметр `validationMessagePosition` для изменения положения сообщения об ошибке. Варианты: `top`, `bottom`, `left`, `right`.

<Source
	code={`<dx-date-range-box meTextArea
[(validationMessageMode)]="validationMessageMode"
[(validationMessagePosition)]="validationMessagePosition">
  <dx-validator>
    <dxi-validation-rule
    type="required"
    message="Required"
    ></dxi-validation-rule>
  </dx-validator>
</dx-date-range-box>`}
	dark
	language="html"
/>

## Формат даты и времени
`dateSerializationFormat` позволяет задать формат даты и времени, которые будут отображаться в компоненте. Примеры вариантов есть выше в контроллерах и на сайте DevExtreme.

<Source
	code={`<dx-date-range-box meDateRangeBox
dateSerializationFormat="dateSerializationFormat"
></dx-date-range-box>`}
	language="html"
	dark
/>

## Настройка дат для выбора

`disabledDates` позволяет задать даты, которые пользователи не могут выбрать.
`calendarOptions` позволяет задать настройки календаря. Необходимо передать объект с настройками. Возможности календаря приведены в документации к соответствующему компоненту DevExtreme.

<Source
	code={`<dx-date-range-box meDateRangeBox
disabledDates="2024-04-22"
calendarOptions="{
  showWeekNumbers: true,
  max: '2024-12-31',
  min: '2023-12-31',}"
></dx-date-range-box>`}
	language="html"
	dark
/>
