# Toast

## Компонент `me-toast`

Компонент `me-toast` расширяет функциональность базового уведомления, предоставляемого директивой `meToast`, которая адаптирует компонент `dx-toast` под требования дизайн-системы. Он позволяет задавать заголовок через свойство `title` и использовать интерактивные кнопки с событиями `onAccept`, `onCancel` и `onClose`. При этом поддерживаются все свойства базового компонента, такие как `message`, `visible`, `type`, `size`, `showIcon`, `position` и `displayTime`. Используйте этот компонент, когда необходимо не только информировать пользователя, но и предоставлять ему возможность взаимодействия с уведомлением.

## Подключение

**Важно:** Компонент `me-toast` является **standalone-компонентом**, и **не входит** в `MeToastModule`.

Несмотря на наличие модуля `MeToastModule`, он относится только к директиве `meToast`, предназначенной для использования с компонентом `dx-toast`. Подключение `MeToastModule` **не даёт доступа к `me-toast`**.

### Подключение в Angular-модуле:
```ts
import { NgModule } from '@angular/core';
import { CommonModule } from '@angular/common';
import { MeToastComponent } from '../../';

@NgModule({
  imports: [
    CommonModule,
    MeToastComponent
  ],
})
export class YourModule {}
```

### Подключение в standalone-компоненте:
```ts
import { Component } from '@angular/core';
import { MeToastComponent } from '../../';

@Component({
  standalone: true,
  selector: 'your-component',
  templateUrl: './your-component.html',
  imports: [MeToastComponent],
})
export class YourComponent {}
```

### Обычный информационный тост

Используется базовый тост без заголовка для простых уведомлений.

<Canvas name="Default" of={toastComponentStories.ContentOnlyMessage} />
<Source
  code={`<dx-toast
  meToast
  [visible]="visible"
  type="info"
  message="Операция выполнена успешно"
>
</dx-toast>`}
  dark
  language="html"
/>

### Расширенный тост с заголовком

Добавление заголовка делает уведомление более информативным.

<Canvas name="Default" of={toastComponentStories.SizeSmall} />
<Source
  code={`<me-toast
  [visible]="visible"
  type="info"
  message="Операция выполнена успешно"
  title="Информация"
>
</me-toast>`}
  dark
  language="html"
/>

### Интерактивный тост с кнопками действий

Предоставляет пользователю возможность принять или отменить действие непосредственно из уведомления.

<Canvas name="Default" of={toastComponentStories.WithActionButtons} />
<Source
  code={`<me-toast
  [visible]="visible"
  type="warning"
  message="Внимание! Требуется подтверждение."
  title="Подтверждение"
  showActionButtons="true"
  (onAccept)="handleAccept()"
  (onCancel)="handleCancel()"
  (onClose)="handleClose()"
>
</me-toast>`}
  dark
  language="html"
/>

### Тост с пользовательским контентом

Этот вариант уведомления позволяет полностью настроить его содержимое с помощью собственного шаблона. Для его использования необходимо задать свойству type значение custom и передать ссылку на шаблон через свойство template. Это решение идеально подходит для интеграции индивидуальных элементов управления и кастомизированных стилей в уведомление.

<Canvas name="Default" of={toastComponentStories.CustomContent} />
<Source
  code={`
<me-toast
  type="custom"
  [visible]="visible"
  [template]="customTemplate"
>
</me-toast>

<ng-template #customTemplate let-content="content">
  <div class='custom-content'>
    <h4 class="me-title-header2">{{ title }}</h4>
    <p class="me-text-body2">{{ message }}</p>
    <div class="actions">
      <dx-button meButton text="Принять" (click)="handleAccept()"></dx-button>
      <dx-button meButton text="Отмена" (click)="handleCancel()"></dx-button>
    </div>
  </div>
</ng-template>`}
  dark
  language="html"
/>
