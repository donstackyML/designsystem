# DataGrid

## Директива `meDataGrid`

Применение директивы `meDataGrid` к элементу `dx-data-grid` приводит его размеры к значению `size=medium` из дизайн-системы, а также приводит отступы в соответствие с дизайн-системой, добавляет свойство `size`.

### Размеры dataGrid

Поддерживает несколько вариаций размеров dataGrid: `small`, `medium` и `large`.

<Source
  code={`
<dx-data-grid
  meDataGrid
  size="medium"
>
</dx-data-grid>`}
  dark
  language="html"
/>

### [DataSource](https://js.devexpress.com/Angular/Documentation/ApiReference/UI_Components/dxDataGrid/Configuration/#dataSource)

`DataGrid` работает с коллекциями объектов. Рекомендуется вам использовать в data простой объект (без цикличных элементов, прототипов и т.д.). `DataGird` использует `JSON.stringify` и другие рекурсивные методы. Циклические ссылки на объекты могут привести к сбою собственных рекурсивных алгоритмов (таких как сериализаторы) из-за переполнения стека.

Пример структуры данных:

<Source
  code={`
dataSource: [
  {
    ID: 1,
    CompanyName: 'Company Name 1',
    Phone: 'Phone 1',
    Fax: 'Fax 1',
    City: 'City 1',
    State: 'State 1',
  },
  {
    ID: 2,
    CompanyName: 'Company Name 2',
    Phone: 'Phone 2',
    Fax: 'Fax 2',
    City: 'City 2',
    State: 'State 2',
  },
  {...}
],
`}
  dark
  language="html"
/>

### Pagination

Для добавления Pagination необходимо использовать `dxo-pager`.
Для контроля колличества строк в таблице необходимо использовать `dxo-paging`.

<Source
  code={`
<dx-data-grid meDataGrid>
  <dxo-pager></dxo-pager>
  <dxo-paging></dxo-paging>
</dx-data-grid>`}
  dark
  language="html"
/>

### Стиль пагинатора

Для изменения стиля Pagination необходимо использовать свойство `displayMode` в `dxo-pager`. По умолчанию значение `full`.

<Source
  code={`<dxo-pager displayMode="full"></dxo-pager>`}
  dark
  language="html"
/>

### Шаблон в таблице

Для добавления каунтеров или инных элементов в ячейках необходимо использовать `cellTemplate` в `dxi-column` и создать шаблон с помощью `*dxTemplate`.

<Canvas of={dataGridStories.WithCounter} />

### [Столбцы](https://js.devexpress.com/Angular/Documentation/ApiReference/UI_Components/dxDataGrid/Configuration/columns/)

Для добавления столбцов необходимо использовать `dxi-column` внутри `dx-data-grid`. Все возможности на [сайте разработчика](https://js.devexpress.com/Angular/Documentation/ApiReference/UI_Components/dxDataGrid/Configuration/columns/)

### [Выравнивание чисел в колонках](https://js.devexpress.com/Angular/Documentation/ApiReference/UI_Components/dxDataGrid/Configuration/alignNumbers/)

Для изменения представления числовых данных в ячейках необходимо использовать `[columnHeaderStyles]` в `dx-data-grid` передать объект наподобие этого: `{ 'ID': 'left', 'Fax': 'left' }` для выравнивания заголовка. Для контента надо задать в `dxi-column` в опции `alignment` соответствующее выравнивание.
