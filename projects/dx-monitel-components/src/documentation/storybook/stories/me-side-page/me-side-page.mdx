# SidePage

## Компонент `me-sidebar`

Компонент `me-side-page` — это универсальный контейнер для отображения боковой панели, предназначенный для показа вспомогательной информации или управления настройками. Он использует архитектуру слотов, что позволяет гибко настраивать его содержимое.

### Слоты (ng-content)

| Название слота     | Описание                                                                                                                             |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| `sidepage-header`  | Контейнер для верхней части боковой панели. Здесь можно разместить заголовок, иконки или кнопки закрытия.                            |
| `sidepage-content` | Контейнер для основного контента боковой панели, например, формы, списки или другие информационные блоки.                            |
| `sidepage-footer`  | Контейнер для нижней части боковой панели, обычно используется для размещения кнопок действий, таких как "Сохранить" или "Отменить". |

### Комплексный пример

В данном примере демонстрируется полноценный компонент `me-side-page`. Он включает в себя три слота:
- **Header:** Для заголовка боковой панели, где можно разместить иконки и кнопки управления.
- **Content:** Основной контент, например, форма настроек с группировкой опций.
- **Footer:** Панель с кнопками действий (например, "Сохранить" и "Отменить").

Также в примере показаны настройки позиционирования, размеров (ширина, минимальная и максимальная ширина) и эффекты затенения.
