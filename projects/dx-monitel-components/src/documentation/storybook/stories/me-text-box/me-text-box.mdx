# TextBox

## Директива `meTextBox`

Применение директивы `meTextBox` к компоненту `dx-text-box` приводит его к оформлению, соответствующему дизайн-системе: задаются стандартные отступы, размеры (по умолчанию — `size="medium"`) и стилизация лейбла. Дополнительно доступны параметры для управления поведением компонента.

### Размеры компонента

Изменение размера текстового поля влияет на отступы, размер шрифта и общую компоновку. Свойство `size` принимает три значения:
- small – уменьшенный размер, подходит для компактных интерфейсов;
- medium – стандартный размер (используется по умолчанию);
- large – увеличенный размер, удобен для форм с более крупным текстом.

### Разные режимы положения лейбла

Директива `meTextBox` позволяет настраивать отображение лейбла с помощью свойства `labelMode`. Это свойство определяет, как и где будет отображаться метка поля, что может помочь улучшить читаемость формы и соответствовать требованиям макета.

#### Лейбл внешний

При значении `labelMode="outside"` лейбл располагается вне поля ввода. Такой вариант часто используется для четкого отделения метки от контрола.

<Canvas name="Лейбл внешний" of={textBoxStories.LabelModeOutside} />

<Source
  code={`<dx-text-box meTextBox labelMode="outside" label="Label"></dx-text-box>`}
  language="html"
  dark
/>

#### Лейбл статичный

Режим `labelMode="static"` фиксирует положение лейбла, не изменяя его при взаимодействии с полем. Это полезно, если требуется постоянное отображение метки в одном месте.

<Canvas name="Лейбл статичный" of={textBoxStories.LabelModeStatic} />

<Source
  code={`<dx-text-box meTextBox labelMode="static" label="Label"></dx-text-box>`}
  language="html"
  dark
/>

#### Лейбл всплывающий

При использовании `labelMode="floating"` лейбл будет перемещаться, когда поле получает фокус. Это создает эффект «плавающего» заголовка, позволяющий экономить пространство внутри поля ввода.

<Canvas name="Лейбл всплывающий" of={textBoxStories.LabelModeFloating} />

<Source
  code={`<dx-text-box meTextBox labelMode="floating" label="Label"></dx-text-box>`}
  language="html"
  dark
/>

#### Лейбл невидимый

Если необходимо скрыть метку (например, при использовании вспомогательных элементов или когда метка выводится иным способом), установите `labelMode="hidden"`. В этом режиме лейбл не отображается в интерфейсе.

<Source
  code={`<dx-text-box meTextBox labelMode="hidden" label="Label"></dx-text-box>`}
  language="html"
  dark
/>

### Изменение положения лейбла с помощью директивы meLabel

Для вывода лейбла вне текстового поля можно использовать директиву `meLabel`. Это позволяет разместить метку отдельно от самого поля, задавая её положение с помощью свойства `labelDirection`.

#### Положение лейбла сверху

Чтобы лейбл располагался над текстовым полем, оберните компонент в контейнер с директивой `meLabel` и установите `labelDirection="column"`. Это позволяет создать вертикальное расположение, где метка находится сверху, а само поле — под ней.

<Canvas name="Лейбл сверху" of={textBoxStories.WithLabelColumn} />

<Source
  code={`
<div meLabel labelDirection="column">
  <span>Label</span>
  <dx-text-box meTextBox labelMode="hidden"></dx-text-box>
</div>
`}
  language="html"
  dark
/>

#### Положение лейбла слева

Чтобы разместить лейбл слева от текстового поля, используйте `labelDirection="row"`. Для корректного выравнивания задайте фиксированную ширину контейнера, например, через атрибут `width`.

<Canvas name="Лейбл слева" of={textBoxStories.WithLabelRow} />

<Source
  code={`
<div meLabel labelDirection="row"  class="dx-widget">
  <span>Label</span>
  <dx-text-box meTextBox labelMode="hidden"></dx-text-box>
</div>
`}
  language="html"
  dark
/>

### Состояния readOnly и disabled

Свойства `readOnly` и `disabled` позволяют управлять интерактивностью текстового поля. В режиме readOnly поле становится доступным для копирования, но редактирование невозможно, а в режиме disabled поле полностью неактивно и выглядит затенённым.

#### Состояние readOnly

<Canvas name="Состояние readOnly" of={textBoxStories.StateReadOnly} />

<Source
  code={`

  meTextBox
  readOnly="true"

</dx-text-box>
  `}

### Использование масок в текстовом поле

Свойство `mask` позволяет задать маску для ввода данных, например, для ввода телефонного номера. Маска указывает, какие символы и в каком формате могут быть введены пользователем.

<Canvas name="Маска для телефона" of={textBoxStories.ModeTelWithMask} />

<Source
  code={`<dx-text-box meTextBox mask="+7 (000) 000-0000"></dx-text-box>`}
  language="html"
  dark
/>

### Показ и скрытие пароля

Для защиты конфиденциальных данных используйте режим `password`. При этом текст поля заменяется на символы-звёздочки, а пользователь может включить или выключить отображение введённого пароля.

<Source
  code={`<dx-text-box meTextBox mode="password"></dx-text-box>`}
