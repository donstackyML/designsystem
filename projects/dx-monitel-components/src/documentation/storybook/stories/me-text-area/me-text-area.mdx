# TextArea

## Директива `meTextArea`

Применение директивы `meTextArea` к компоненту `dx-text-area` приводит его к оформлению, соответствующему дизайн-системе: задаются стандартные отступы, размеры (по умолчанию — `size="medium"`) и стилизация лейбла. Дополнительно доступны параметры для управления поведением компонента.

### Изменение положения лейбла с помощью директивы meLabel

Для вывода лейбла вне текстового поля можно использовать директиву `meLabel`. Это позволяет разместить метку отдельно от самого поля, задавая её положение с помощью свойства `labelDirection`.

#### Положение лейбла сверху

Чтобы лейбл располагался над текстовым полем, оберните компонент в контейнер с директивой `meLabel` и установите `labelDirection="column"`. Это позволяет создать вертикальное расположение, где метка находится сверху, а само поле — под ней.

<Canvas name="Лейбл сверху" of={textAreaStories.WithLabelColumn} />

<Source
  code={`
<div meLabel labelDirection="column">
  <span>Label</span>
  <dx-text-area meTextArea labelMode="hidden"></dx-text-area>
</div>
`}
  language="html"
  dark
/>

#### Положение лейбла слева

Чтобы разместить лейбл слева от текстового поля, используйте `labelDirection="row"`. Для корректного выравнивания задайте фиксированную ширину контейнера, например, через атрибут `width`.

<Canvas name="Лейбл слева" of={textAreaStories.WithLabelRow} />

<Source
  code={`
<div meLabel labelDirection="row" width="250px" class="dx-widget">
  <span>Label</span>
  <dx-text-area meTextArea labelMode="hidden"></dx-text-area>
</div>
`}
  language="html"
  dark
/>

### Валидация поля

Для валидации используйте `<dx-validator>` внутри тэга `dx-text-area`. Для добавления валидации используйте тэг `<dxi-validation-rule>` и параметры `type` и `message`.
Не забудьте импортировать `DxTextAreaModule` и `DxValidatorModule`.
Используйте параметры `validationMessageMode` для изменения режима отображения сообщения об ошибке. Варианты: `auto` и `always`.
Используйте параметр `validationMessagePosition` для изменения положения сообщения об ошибке. Варианты: `top`, `bottom`, `left`, `right`.

<Source
	code={`<dx-text-area meTextArea
  [(validationMessageMode)]="validationMessageMode"
  [(validationMessagePosition)]="validationMessagePosition">
  <dx-validator>
    <dxi-validation-rule
    type="required"
    message="Required"
    ></dxi-validation-rule>
  </dx-validator>
</dx-text-area>`}
	dark
	language="html"
/>
