# DropDownButton

## Директива meDropDownButton

Директива `meDropDownButton` расширяет базовую функциональность элемента `dx-drop-down-button`, адаптируя его под требования дизайн-системы. Он устанавливает размеры (по умолчанию — `medium` или 32px), поддерживает стилизацию, добавление иконки и работу с выпадающим списком, а также предоставляет возможность использовать разделённую кнопку.

### Видимость разделителей

Свойство `dividersVisibility` определяет видимость разделителей у элементов списка в выпадающем меню:

- `none` — разделители отсутствуют.
- `all` — разделители отображаются между всеми элементами.
- `auto` — разделители отображаются автоматически, в зависимости от данных.

#### Без разделителей

<Canvas name="DividersVisibilityNone" of={dropDownButtonStories.DividersVisibilityNone} />
<Source
  code={`<dx-drop-down-button
  meDropDownButton
  [dividersVisibility]="'none'"
  [items]="items">
</dx-drop-down-button>`}
  dark
  language="html"
/>

#### Все разделители

<Canvas name="DividersVisibilityAll" of={dropDownButtonStories.DividersVisibilityAll} />
<Source

  meDropDownButton
  [dividersVisibility]="'all'"
  [items]="items">
</dx-drop-down-button>`}
  dark
  language="html"
/>

#### Добавление разделителей в элементы списка

Чтобы добавить разделитель между элементами списка, используйте свойство `hasDivider`. Если у элемента списка это свойство установлено в `true`, то после него будет добавлен разделитель.

Пример данных с использованием `hasDivider`:

<Canvas name="DividersVisibilityByContent" of={dropDownButtonStories.DividersVisibilityByContent} />
<Source
  code={`
<dx-drop-down-button
  meDropDownButton
  [dividersVisibility]="'auto'"
  [items]="items">
</dx-drop-down-button>

const items = [
  {
    id: 1,
    name: 'Фиксированный диапазон времени',
    hasDivider: true
  },
  {
    id: 4,
    name: 'Абсолютное время',
    hasDivider: false
  },
  {
    id: 2,
    name: 'Относительное время, обн 10 сек.',
    hasDivider: true
  },
  {
    id: 3,
    name: 'Пункт 1',
    hasDivider: false
  },
];
  `}
  dark
  language="html"
/>
