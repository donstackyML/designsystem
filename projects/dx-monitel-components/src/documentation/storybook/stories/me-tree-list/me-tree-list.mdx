# TreeList

## Директива `meTreeList`

Директива `meTreeList` настраивает внешний вид компонента `dx-tree-list` согласно дизайн-системе. Компонент поддерживает как простое отображение, так и иерархические структуры с возможностью редактирования, валидации и выбора строк. Дополнительно можно настраивать отображение столбцов, поведение фильтрации и сортировки, а также использовать шаблоны для кастомизации ячеек.

### Добавление колонки

Для добавления новых столбцов используйте элемент `<dxi-column>`, указывая имя поля в `dataField` и заголовок в `caption`. Контент ячеек можно настраивать через шаблоны с помощью директивы `dxTemplate`.

<Source
  code={`
<dxi-column dataField="Full_Name" caption="Name"></dxi-column>
`}
  dark
  language="html"
/>

<Canvas name="Колонки" of={treeListStories.WithColumns} />

### Кнопки в TreeList

Для добавления кнопок действий (редактирование, сохранение, удаление) используйте столбец с типом `buttons` и элементы `<dxi-button>`. Режим редактирования задается через `<dxo-editing>`.

<Canvas name="Кнопки" of={treeListStories.WithEditingButtons} />

### Валидация данных

Пример демонстрирует валидацию данных в столбце. Для этого в элементе `<dxi-column>` используется `<dxi-validation-rule>`, где можно указать тип валидации и сообщение об ошибке.

<Source
  code={`
<dxi-column dataField="Full_Name" caption="Name">
  <dxi-validation-rule type="required"></dxi-validation-rule>
</dxi-column>
`}
  dark
  language="html"
/>

<Canvas name="Валидация" of={treeListStories.WithValidation} />

### Режим выбора элементов

Чтобы управлять возможностью выбора строк, используйте элемент `<dxo-selection>` с атрибутом `mode`, например, `"single"` или `"multiple"`.

<Source
  code={`
<dx-tree-list meTreeList>
  <dxo-selection [mode]="'multiple'"></dxo-selection>
</dx-tree-list>
`}
  dark
  language="html"
/>

### Иерархическая структура

Пример демонстрирует TreeList с вложенными узлами. Используйте свойства `parentIdExpr` и `keyExpr` для построения иерархии.

<Canvas name="TreeList с иерархией" of={treeListStories.WithHierarchy} />

<Source
  code={`
<dx-tree-list meTreeList
  [(dataSource)]="dataSource"
  keyExpr="ID"
  parentIdExpr="Head_ID"
  [autoExpandAll]="true">
  <dxi-column dataField="Full_Name" caption="Name"></dxi-column>
  <dxi-column dataField="Title" caption="Position"></dxi-column>
</dx-tree-list>
  `}
  dark
  language="html"
/>

### Сортировка и фильтрация

Данный пример показывает, как включить строку фильтрации и разрешить сортировку столбцов. Это помогает пользователю быстрее находить нужные данные.

### Кастомные ячейки

Для кастомизации содержимого ячеек используйте директиву `dxTemplate`. В примере ниже показан кастомный шаблон для отображения статуса с изменением цвета.

<Canvas name="Кастомные ячейки" of={treeListStories.WithCustomCells} />

<Source
  code={`
<dx-tree-list meTreeList [dataSource]="dataSource" keyExpr="ID">
  <dxi-column dataField="Full_Name" caption="Name"></dxi-column>
  <dxi-column dataField="Title" caption="Position"></dxi-column>
  <dxi-column caption="Status" cellTemplate="statusTemplate"></dxi-column>

  <div *dxTemplate="let cell of 'statusTemplate'">
    <span [style.color]="cell.data.Status === 'active' ? 'green' : 'red'">
      {{ cell.data.Status }}
    </span>
  </div>
</dx-tree-list>
  `}
  dark
  language="html"
/>

### DataStructure

Свойство `dataStructure` определяет, как интерпретировать структуру данных, передаваемых в TreeList.

При значении `plain` данные представлены в виде плоского массива, а при значении `tree` ожидается иерархическая структура, где каждый элемент имеет уникальный идентификатор и ссылку на родительский элемент (например, через `Head_ID`). Элементы верхнего уровня должны иметь `Head_ID`, равный `0`, `null` или `undefined`. Дополнительную информацию можно найти в [руководстве по группировке TreeList](https://js.devexpress.com/Angular/Documentation/Guide/UI_Components/TreeList/Grouping/).

<Source
  code={`
var treeListData = [
  { id: 1, parentId: 0, text: "Root 1" },
  { id: 2, parentId: 1, text: "Child 1" },
  { id: 3, parentId: 1, text: "Child 2" },
  { id: 4, parentId: 0, text: "Root 2" },
];
  `}
  dark
  language="js"
/>

<Source
  code={`
<dx-tree-list
  meTreeList
  [dataSource]="dataSource"
  keyExpr="ID"
  parentIdExpr="Head_ID">
</dx-tree-list>
  `}
  dark
  language="html"
/>
