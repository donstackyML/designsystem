## [DataSource](https://js.devexpress.com/Angular/Documentation/ApiReference/UI_Components/dxPivotGrid/Configuration/#dataSource)

`PivotGrid` привязывается к данным через [PivotGridDataSource](https://js.devexpress.com/Angular/Documentation/ApiReference/Data_Layer/PivotGridDataSource/), компонент, который позволяет вам сортировать, фильтровать, группировать и выполнять другие операции формирования данных.

Чтобы привязать `PivotGrid` к данным, присвойте `PivotGridDataSource` свойству `DataSource` компонента. Также укажите массив `fields`[] для настройки полей `PivotGrid`. [Демо](https://js.devexpress.com/Angular/Demos/WidgetsGallery/Demo/PivotGrid/SimpleArray/Light/).

## Добавление инструментов

PivotGrid имеет свои инструменты, такие как `field chooser`, `field panel`, `header filter`, `load panel` и т.д. См. в [API компонента](https://js.devexpress.com/Angular/Documentation/ApiReference/UI_Components/dxPivotGrid/).

Для использования инструментов вам необходимо добавить соответствующие тэги в компонент `PivotGrid`.

<Source
  code={`
<pivot-grid mePivotGrid [dataSource]="Sales">
  <dxo-field-chooser [enabled]="true"></dxo-field-chooser>
  <dxo-scrolling mode="virtual"></dxo-scrolling>
  <dxo-load-panel
    meLoadPanel
    size="small"
    showPane="false"
    text="Загрузка..."
    [enabled]="true"
  ></dxo-load-panel>
</pivot-grid>
`}
  dark
  language="html"
/>
