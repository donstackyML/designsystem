### Видимость разделителей

Свойство `dividersVisibility` определяет видимость разделителей в меню:

- `none` — разделители отсутствуют.
- `all` — разделители отображаются между всеми элементами.
- `auto` — разделители отображаются автоматически, в зависимости от данных.

#### Без разделителей

<Canvas name="DividersVisibilityNone" of={contextMenuStories.DividersVisibilityNone} />
<Source
  code={`<dx-context-menu
  meContextMenu
  [dividersVisibility]="'none'"
  [dataSource]="dataSource">
</dx-context-menu>`}
  dark
  language="html"
/>

#### Все разделители

<Canvas name="DividersVisibilityAll" of={contextMenuStories.DividersVisibilityAll} />
<Source
  code={`<dx-context-menu
  meContextMenu
  [dividersVisibility]="'all'"
  [dataSource]="dataSource">
</dx-context-menu>`}
  dark
  language="html"
/>

#### Добавление разделителей в элементы списка

Чтобы добавить разделитель между элементами списка, используйте свойство `hasDivider`. Если у элемента списка это свойство установлено в `true`, то после него будет добавлен разделитель.

Пример данных с использованием `hasDivider`:

<Canvas name="DividersVisibilityByContent" of={contextMenuStories.DividersVisibilityByContent} />
<Source
  code={`<dx-context-menu
  meContextMenu
  [dividersVisibility]="'auto'"
  [dataSource]="dataSource">
</dx-context-menu>

const dataSource = [
  {
    text: 'Electronics',
    hasDivider: true,
    items: [
      { text: 'Computers', hasDivider: true },
      { text: 'Phones', hasDivider: false },
    ],
  },
  {
    text: 'Entertainment',
    hasDivider: false,
    items: [
      { text: 'Films & Music', hasDivider: true },
      { text: 'Games & Toys', hasDivider: false },
    ],
  },
];
`}
  dark
  language="html"
/>

Чтобы элемент использовался в качестве заголовка группы, обязательно указывайте `beginGroup: true` и `disabled: true`.

    icon: 'public',

      { icon: 'menu_book', text: 'Facebook', selected: true },
