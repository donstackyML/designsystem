# Form

## Директива `meForm`

Директива `meForm` стилизует компонент `dx-form` в соответствии с требованиями дизайн-системы. Она работает совместно с такими директивами, как `meTextBox`, `meSelectBox` и `meCheckBox`, обеспечивая единый внешний вид и поведение для всех элементов формы.

### Базовая форма

*Этот пример демонстрирует простейшую форму, состоящую из двух полей: "First Name" и "Email". Здесь используются свойства `formData` для передачи данных, а также базовые директивы для стилизации полей (например, `meTextBox`).*

<Canvas name="Базовая форма" of={formStories.Default} />

<Source
  code={`
<dx-form
  meForm
  [formData]="formData"
>
  <dxi-item dataField="firstName">
    <dxo-label text="First Name"></dxo-label>
    <div *dxTemplate>
      <dx-text-box meTextBox [(value)]="formData.firstName"></dx-text-box>
    </div>
  </dxi-item>
  <dxi-item dataField="email">
    <dxo-label text="Email"></dxo-label>
    <div *dxTemplate>
      <dx-text-box meTextBox [(value)]="formData.email"></dx-text-box>
    </div>
  </dxi-item>
</dx-form>
  `}
  dark
  language="html"
/>

### Группировка полей

*Для группировки полей используется свойство `itemType="group"` у компонента `dxi-item`. Дополнительно, можно задать заголовок группы с помощью свойства `caption`. В данном примере поля, относящиеся к персональным данным, объединены в группу с заголовком "Personal Info", а контактная информация — в группу "Contact Info".*

<Canvas name="Группировка полей" of={formStories.WithGrouping} />

<Source
  code={`
<dx-form meForm [formData]="formData">
  <!-- Группа для персональной информации -->
  <dxi-item itemType="group" caption="Personal Info">
    <dxi-item meFormItem dataField="firstName">
      <dxo-label text="First Name"></dxo-label>
      <div *dxTemplate>
        <dx-text-box meTextBox></dx-text-box>
      </div>
    </dxi-item>
    <dxi-item meFormItem dataField="lastName">
      <dxo-label text="Last Name"></dxo-label>
      <div *dxTemplate>
        <dx-text-box meTextBox></dx-text-box>
      </div>
    </dxi-item>
  </dxi-item>
  <!-- Группа для контактной информации -->
  <dxi-item itemType="group" caption="Contact Info">
    <dxi-item meFormItem dataField="phone">
      <dxo-label text="Phone"></dxo-label>
      <div *dxTemplate>
        <dx-text-box meTextBox></dx-text-box>
      </div>
    </dxi-item>
    <dxi-item meFormItem dataField="email">
      <dxo-label text="Email"></dxo-label>
      <div *dxTemplate>
        <dx-text-box meTextBox></dx-text-box>
      </div>
    </dxi-item>
  </dxi-item>
</dx-form>
  `}
  dark
  language="html"
/>

### Валидация

*В этом примере для поля "Email" настроены два правила валидации: `required` и `email`. Используя директиву `meForm`, вы можете легко интегрировать правила валидации через компоненты `dxi-validation-rule`, чтобы обеспечить корректность вводимых данных.*

<Canvas name="Валидация" of={formStories.WithValidation} />

<Source
  code={`
<dx-form meForm>
  <dxi-item dataField="email">
    <dxi-validation-rule type="required" message="Email is required"></dxi-validation-rule>
    <dxi-validation-rule type="email" message="Invalid email format"></dxi-validation-rule>
    <div *dxTemplate>
      <dx-text-box meTextBox></dx-text-box>
    </div>
  </dxi-item>
</dx-form>
  `}
  dark
  language="html"
/>

### Форма с динамической логикой

*Этот пример демонстрирует динамическое изменение структуры формы. При выборе опции "Есть детали?" (свойство `hasDetails`) с помощью чекбокса, появляется дополнительное поле "Детали". Для этого используется конструкция `*ngIf`, которая отображает элемент `dxi-item` только при выполнении условия.*

<Canvas name="Динамическая форма" of={formStories.DynamicForm} />

<Source
  code={`
<dx-form meForm [formData]="formData">
  <dxi-item dataField="hasDetails">
    <dxo-label text="Есть детали?"></dxo-label>
    <div *dxTemplate>
      <dx-check-box meCheckBox [(value)]="formData.hasDetails"></dx-check-box>
    </div>
  </dxi-item>
  <!-- Поле "Детали" отображается только если hasDetails === true -->
  <dxi-item *ngIf="formData.hasDetails" dataField="details">
    <dxo-label text="Детали"></dxo-label>
    <div *dxTemplate>
      <dx-text-box meTextBox [(value)]="formData.details"></dx-text-box>
    </div>
  </dxi-item>
</dx-form>
  `}
  dark
  language="html"
/>

### Разные режимы положения лейбла

*В этом блоке показаны различные варианты отображения лейблов для полей формы. Это достигается с помощью свойств `labelMode` и `labelLocation`. Вы можете выбрать, где располагать лейбл: слева, сверху или полностью скрыть его.*

#### Лейбл слева

*Свойство `labelLocation="left"` размещает лейбл слева от поля ввода.*

<Canvas name="Лейбл слева" of={formStories.LabelLocationLeft} />

<Source

    </div>
  </dxi-item>
  <dxi-item dataField="email">
    <dxo-label text="Email"></dxo-label>
    <div *dxTemplate>
      <dx-text-box meTextBox [(value)]="formData.email"></dx-text-box>

</dx-form>

  language="html"
