# Pagination

## Компонент `me-pagination`

Компонент `me-pagination` предоставляет удобный интерфейс для навигации по страницам данных, включая возможность выбора количества элементов на странице и отображение общего количества элементов.

### Использование кнопок контролирующих количество элементов на странице

#### Использование кнопки с выпадающим списком

*По умолчанию компонент предоставляет выпадающий список для выбора количества элементов на странице, но вы можете отключить его, установив параметр `useButtons` в `false`. Чтобы задать варианты количества элементов на странице, используйте параметр `itemsPerPageOptions`.*

<Canvas name="PageSizeControlWithDropDownButton" of={paginationStories.PageSizeControlWithDropDownButton} />
<Source
  code={`
<me-pagination
  totalItems="100"
  itemsPerPageOptions="[10, 20, 30]"
>
</me-pagination>`}
  language="html"
  dark
/>

#### Использование группы кнопок

*Чтобы использовать группу кнопок, необходимо установить параметр `useButtons` в `true`. Для задания вариантов количества элементов на странице, используйте параметр `itemsPerPageOptions`.*

<Canvas name="PageSizeControlWithButtons" of={paginationStories.PageSizeControlWithButtons} />
<Source
  code={`
<me-pagination
  totalItems="100"
  itemsPerPageOptions="[10, 20, 30]"
  useButtons="true"
>
</me-pagination>`}
  language="html"
  dark
/>

#### Без использования контролирующих кнопок

*Если вам не нужно использовать кнопки контролирующих количество элементов на странице, установите параметр `hasPageSizeControlButtons` в `false`.*

<Canvas name="WithoutPageSizeControlButtons" of={paginationStories.WithoutPageSizeControlButtons} />
<Source
  code={`
<me-pagination
  totalItems="100"
  hasPageSizeControlButtons="false"
>
</me-pagination>`}
  language="html"
  dark
/>

### Обработка событий

*Компонент Pagination поддерживает события для отслеживания изменений страницы и количества элементов на странице.*

<Source
  code={`
<me-pagination
  [totalItems]="100"
  [itemsPerPage]="10"
  [currentPage]="1"
  [maxVisiblePages]="5"
  (pageChange)="onPageChange($event)"
  (itemsPerPageChange)="onItemsPerPageChange($event)"
></me-pagination>

// В вашем компоненте:
onPageChange(newPage: number) {
  console.log('Страница изменена:', newPage);
}

onItemsPerPageChange(newItemsPerPage: number) {
  console.log('Изменено количество элементов на странице:', newItemsPerPage);
}

`}
dark
language="typescript"
/>

*Это позволяет вам реагировать на изменения страницы и количества элементов на странице для обновления данных или выполнения других действий в вашем приложении.*

### Настройка пагинации для таблицы данных

*Вы можете использовать компонент пагинации вместе с таблицей данных для создания полнофункционального интерфейса навигации. Это может быть полезно, например, при отображении большого количества данных в таблице.*

<Source
  code={`
<table>
  <!-- Ваши данные таблицы -->
</table>

<me-pagination
[totalItems]="500"
[itemsPerPage]="50"
[currentPage]="1"
[maxVisiblePages]="5"
(pageChange)="onPageChange($event)"
    (itemsPerPageChange)="onItemsPerPageChange($event)"

> </me-pagination>
`}
  dark
  language="html"
/>

*В этом примере мы создаем пагинацию для таблицы с 500 элементами, отображая по 50 элементов на странице. При изменении страницы или количества элементов на странице вы можете обновлять данные таблицы соответствующим образом.*
