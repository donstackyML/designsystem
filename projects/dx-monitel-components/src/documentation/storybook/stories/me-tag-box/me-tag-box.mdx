# TagBox

## Директива `meTagBox`

Применение директивы `meTagBox` к компоненту `dx-tag-box` приводит его размеры к значению `size="medium"` из дизайн-системы, а также приводит отступы в соответствие с дизайн-системой, добавляет свойство `size`.

### Размеры компонента

Изменение размера текстового поля влияет на отступы, размер шрифта и общую компоновку. Свойство `size` принимает три значения:
- small – уменьшенный размер, подходит для компактных интерфейсов;
- medium – стандартный размер (используется по умолчанию);
- large – увеличенный размер, удобен для форм с более крупным текстом.

### Разные режимы положения лейбла

Директива `meTagBox` позволяет настраивать отображение лейбла с помощью свойства `labelMode`. Это свойство определяет, как и где будет отображаться метка поля, что может помочь улучшить читаемость формы и соответствовать требованиям макета.

#### Лейбл внешний

При значении `labelMode="outside"` лейбл располагается вне поля ввода. Такой вариант часто используется для четкого отделения метки от контрола.

<Canvas name="Лейбл внешний" of={tagBoxStories.LabelModeOutside} />

<Source
  code={`<dx-tag-box meTagBox labelMode="outside" label="Label"></dx-tag-box>`}
  language="html"
  dark
/>

#### Лейбл статичный

Режим `labelMode="static"` фиксирует положение лейбла, не изменяя его при взаимодействии с полем. Это полезно, если требуется постоянное отображение метки в одном месте.

<Canvas name="Лейбл статичный" of={tagBoxStories.LabelModeStatic} />

<Source
  code={`<dx-tag-box meTagBox labelMode="static" label="Label"></dx-tag-box>`}
  language="html"
  dark
/>

#### Лейбл всплывающий

При использовании `labelMode="floating"` лейбл будет перемещаться, когда поле получает фокус. Это создает эффект «плавающего» заголовка, позволяющий экономить пространство внутри поля ввода.

<Canvas name="Лейбл всплывающий" of={tagBoxStories.LabelModeFloating} />

<Source
  code={`<dx-tag-box meTagBox labelMode="floating" label="Label"></dx-tag-box>`}
  language="html"
  dark
/>

#### Лейбл невидимый

Если необходимо скрыть метку (например, при использовании вспомогательных элементов или когда метка выводится иным способом), установите `labelMode="hidden"`. В этом режиме лейбл не отображается в интерфейсе.

<Canvas name="Лейбл невидимый" of={tagBoxStories.LabelModeHidden} />

<Source
  code={`<dx-tag-box meTagBox labelMode="hidden" label="Label"></dx-tag-box>`}
  language="html"
  dark
/>

### Изменение положения лейбла с помощью директивы meLabel

Для вывода лейбла вне текстового поля можно использовать директиву `meLabel`. Это позволяет разместить метку отдельно от самого поля, задавая её положение с помощью свойства `labelDirection`.

#### Положение лейбла сверху

Чтобы лейбл располагался над текстовым полем, оберните компонент в контейнер с директивой `meLabel` и установите `labelDirection="column"`. Это позволяет создать вертикальное расположение, где метка находится сверху, а само поле — под ней.

<Canvas name="Лейбл сверху" of={tagBoxStories.WithLabelColumn} />

<Source
  code={`
<div meLabel labelDirection="column">
  <span>Label</span>
  <dx-tag-box meTagBox labelMode="hidden"></dx-tag-box>
</div>
`}
  language="html"
  dark
/>

#### Положение лейбла слева

Чтобы разместить лейбл слева от текстового поля, используйте `labelDirection="row"`. Для корректного выравнивания задайте фиксированную ширину контейнера, например, через атрибут `width`.

<Canvas name="Лейбл слева" of={tagBoxStories.WithLabelRow} />

<Source
  code={`
<div meLabel labelDirection="row"  class="dx-widget">
  <span>Label</span>
  <dx-tag-box meTagBox labelMode="hidden"></dx-tag-box>
</div>
`}
  language="html"
  dark
/>

### Видимость разделителей

Свойство `dividersVisibility` определяет видимость разделителей у элементов списка в выпадающем меню:

- `none` — разделители отсутствуют.
- `all` — разделители отображаются между всеми элементами.
- `auto` — разделители отображаются автоматически, в зависимости от данных.

### Режимы применения значений

Свойство `applyValueMode` управляет тем, когда выбранные значения будут применяться к компоненту.

#### Применение значений мгновенно (ApplyInstantly)

При значении `applyValueMode="instantly"` выбранное значение применяется сразу после выбора без дополнительных подтверждений. Это удобно в сценариях, когда требуется моментальное обновление данных, например, при фильтрации или динамическом обновлении интерфейса.

<Canvas name="ApplyInstantly" of={tagBoxStories.ApplyInstantly} />
<Source
  code={`
<dx-tag-box
  meTagBox
  applyValueMode="instantly"
  [dataSource]="items"
  [value]="selectedValues"
></dx-tag-box>
  `}
  language="html"
  dark
/>

#### Применение значений по кнопке (ApplyWithButtons)

При значении `applyValueMode="useButtons"` изменения применяются только после нажатия соответствующей кнопки, что позволяет пользователю сначала внести несколько изменений и затем подтвердить их. Это особенно полезно, когда требуется дополнительное подтверждение выбора, например, при редактировании сложных фильтров или данных, где изменения могут быть критичными.

<Canvas name="ApplyWithButtons" of={tagBoxStories.ApplyWithButtons} />

<Source
  code={`
<dx-tag-box
  meTagBox
  applyValueMode="useButtons"
  [dataSource]="items"
  [value]="selectedValues"
></dx-tag-box>
  `}
  language="html"

### Валидация поля

Чтобы добавить валидацию в компонент `<dx-tag-box>`, используйте вложенный компонент `<dx-validator>`, который содержит один или несколько элементов `<dxi-validation-rule>`. Каждый элемент `<dxi-validation-rule>` позволяет задать правило валидации, определяя его тип с помощью свойства `type` и сообщение об ошибке через свойство `message`. Не забудьте импортировать модуль `DxValidatorModule` в ваш модуль приложения. Дополнительно вы можете управлять режимом отображения сообщений об ошибке с помощью параметра `validationMessageMode` (варианты: `auto` и `always`), а также задавать их положение с помощью параметра `validationMessagePosition` (варианты: `top`, `bottom`, `left`, `right`).

<Source
  code={`
<dx-tag-box
  meTagBox
  [(validationMessageMode)]="validationMessageMode"
  [(validationMessagePosition)]="validationMessagePosition">
  <dx-validator>
    <dxi-validation-rule
      type="required"
      message="Required">
    </dxi-validation-rule>
  </dx-validator>
</dx-tag-box>
  `}
  dark
  language="html"
/>

### Элементы контента

#### Группировка элементов

Компонент TagBox позволяет группировать элементы. Для этого используйте свойство `grouped` и передавайте данные в `dataSource`. Подробнее про группировку можно узнать в документации компонента TagBox [здесь](https://js.devexpress.com/Angular/Documentation/Guide/UIComponents/TagBox/Grouping/IntheDataSource/).

<Canvas name="Группировка элементов" of={tagBoxStories.GroupedItems} />

<Source
  code={`
<dx-tag-box
  meTagBox
  [dataSource]="dataSource"
  [grouped]="true"
  displayExpr="Name"
  valueExpr="ID"
>
</dx-tag-box>
  `}
  dark
  language="html"
/>

#### Группировка элементов с иконками

В этом примере к заголовкам групп добавлены иконки. Для этого переопределяется шаблон группы через директиву `dxTemplate` и выводится иконка вместе с текстом заголовка. Подробнее про группировку можно узнать в документации компонента TagBox [здесь](https://js.devexpress.com/Angular/Documentation/Guide/UIComponents/TagBox/Grouping/IntheDataSource/).

<Canvas name="Группировка элементов с иконками" of={tagBoxStories.CustomTemplateWithGroupsHeaderIcon} />

<Source
  code={`
<dx-tag-box
  meTagBox
  [dataSource]="dataSource"
  [grouped]="true">
  <div dxTemplate="let data of 'group'">
    <div class="custom-icon">
      <span class="dx-icon-globe icon"></span>
      {{ data.key }}
    </div>
  </div>
</dx-tag-box>
  `}
  dark

### Ограничения отображения тегов

#### Ограничение количества тегов

Свойство `maxDisplayedTags` позволяет ограничить количество тегов, отображаемых в поле. Если количество выбранных тегов превышает указанное значение, оставшиеся теги будут скрыты за дополнительным элементом с информацией о количестве.

<Canvas name="Ограничение количества тегов" of={tagBoxStories.WithMaxDisplayedTags} />

<Source
  code={`
<dx-tag-box
  meTagBox
  [maxDisplayedTags]="3"
  [value]="generateItems(7)">
</dx-tag-box>
  `}
  dark
  language="html"
/>

#### Ограничение тегов без мульти-тега

Если вы хотите, чтобы скрывались теги без отображения группового элемента (multi-tag), установите свойство `showMultiTagOnly` в значение `false` вместе с `maxDisplayedTags`.

<Canvas name="Ограничение тегов без мульти-тега" of={tagBoxStories.WithMaxDisplayedTagsWithoutMultiTagOnly} />

<Source
  code={`
<dx-tag-box
  meTagBox
  [maxDisplayedTags]="3"
  [value]="generateItems(7)"
  [showMultiTagOnly]="false">
</dx-tag-box>
  `}
  dark
  language="html"
/>
