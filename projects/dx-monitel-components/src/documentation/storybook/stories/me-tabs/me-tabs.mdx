# Tabs

## Директива `meTabs`

Директива `meTabs` стилизует компонент `dx-tabs` согласно дизайн-системе, позволяя изменять размер, ориентацию, стиль отображения и расположение иконок. Ниже приведены примеры, где для каждого варианта кратко указано, какое свойство используется для настройки.

### Навигация

В примерах ниже показаны два способа управления навигацией в компоненте: с помощью кнопок навигации и прокрутки по содержимому.

#### Навигация с кнопками

Свойство `showNavButtons="true"` включает кнопки для навигации, если вкладок много.

<Canvas name="Навигация с кнопками" of={tabsStories.NavigationWithButtons} />

<Source
  code={`<dx-tabs meTabs showNavButtons="true" width="300px" [dataSource]="defaultTabsData"></dx-tabs>`}
  language="html"
  dark
/>

#### Прокрутка по содержимому

Свойство `scrollByContent="true"` позволяет прокручивать вкладки путем перетаскивания содержимого.

<Canvas name="Прокрутка по содержимому" of={tabsStories.NavigationWithScroll} />

<Source
  code={`<dx-tabs meTabs scrollByContent="true" width="300px" [dataSource]="defaultTabsData"></dx-tabs>`}

  dark

### Прочие настройки

#### Режим RTL

Свойство `rtlEnabled="true"` включает отображение справа налево, подходящее для языков с соответствующей локализацией.

<Canvas name="Режим RTL" of={tabsStories.RightToLeft} />

<Source
  code={`<dx-tabs meTabs rtlEnabled="true" [dataSource]="defaultTabsData"></dx-tabs>`}
  language="html"
  dark
/>

#### Растяжение вкладок

Свойство `stretchTabs="true"` заставляет вкладки равномерно распределяться по всей ширине контейнера.

<Canvas name="Растянутые вкладки" of={tabsStories.StretchTabs} />

<Source
  code={`<dx-tabs meTabs stretchTabs="true" width="100vw" [dataSource]="defaultTabsData"></dx-tabs>`}

  dark
