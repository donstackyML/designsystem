# Property Grid

## Компонент (`me-property-grid`)

Компонент `me-property-grid` предназначен для отображения и редактирования набора свойств объекта в виде таблицы из двух колонок: название свойства и его значение/редактор. Он поддерживает изменение ширины колонок, сворачивание/разворачивание и различные способы предоставления данных.

<Controls of={gridStories.Default} />

## Компонент (`me-property-grid-cell`)

Компонент `me-property-grid-cell` представляет собой элемент в `me-property-grid`. Он отвечает за отображение названия свойства и его значения или редактора.

<Controls of={cellStories.Default} />

## Компонент (`me-property-grid-group`)

Компонент `me-property-grid-group` служит оберткой для нескольких экземпляров `me-property-grid`. Он создает единую прокручиваемую область для всех вложенных гридов и позволяет управлять общими параметрами отображения, такими как высота и отступы между гридами.

<Controls of={gridGroupStories.Default} />

### Синхронизация ширины столбцов в группе (`synchronizeColumnWidths`)

Установка свойства `synchronizeColumnWidths="true"` на компоненте `me-property-grid-group` позволяет синхронизировать ширину столбцов всех вложенных `me-property-grid`. При изменении ширины столбцов одного грида все остальные гриды в группе автоматически обновят свои столбцы до той же ширины.
