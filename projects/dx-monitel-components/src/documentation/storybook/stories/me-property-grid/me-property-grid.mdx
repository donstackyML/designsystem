# Property Grid

## Компонент (`me-property-grid`)

Компонент `me-property-grid` предназначен для отображения и редактирования набора свойств объекта в виде таблицы из двух колонок: название свойства и его значение/редактор. Он поддерживает изменение ширины колонок, сворачивание/разворачивание и различные способы предоставления данных.

<Controls of={gridStories.Default} />

## Компонент (`me-property-grid-cell`)

Компонент `me-property-grid-cell` представляет собой элемент в `me-property-grid`. Он отвечает за отображение названия свойства и его значения или редактора.

<Controls of={cellStories.Default} />

## Примеры использования `me-property-grid`

### Стандартное использование (Content Projection)

Наиболее распространенный способ использования - передача `me-property-grid-cell` компонентов внутрь `me-property-grid`.

<Canvas of={gridStories.Default} />
<Source of={gridStories.Default} dark />

### С действиями в заголовке

Можно добавить кастомные элементы (иконки, кнопки) слева и справа в заголовке грида с помощью слотов `property-grid-header-left-actions` и `property-grid-header-right-actions`.

<Canvas of={gridStories.WithHeaderActions} />
<Source of={gridStories.WithHeaderActions} dark />

### Использование `dataSource`

Альтернативный способ заполнения грида - через входное свойство `dataSource`.

<Canvas of={gridStories.WithDataSource} />
<Source of={gridStories.WithDataSource} dark />

### С различными типами полей ввода

Демонстрация интеграции различных DevExtreme контролов в ячейки грида.

<Canvas of={gridStories.WithVariousInputs} />
<Source of={gridStories.WithVariousInputs} dark />

### С фиксированной высотой и прокруткой

Если количество свойств велико, можно ограничить высоту грида с помощью свойства `height`, что приведет к появлению вертикальной прокрутки.

<Canvas of={gridStories.WithFixedHeightAndScroll} />
<Source of={gridStories.WithFixedHeightAndScroll} dark />

### Изначально свернутый

Грид можно инициализировать в свернутом состоянии, установив `isOpen` в `false`.

<Canvas of={gridStories.InitiallyClosed} />
<Source of={gridStories.InitiallyClosed} dark />
