# ColorBox

## Директива `meColorBox`

Директива `meColorBox` применяется к компоненту `dx-color-box` для кастомизации его внешнего вида и поведения в соответствии с дизайн-системой. Она добавляет поддержку размеров (small, medium, large), настраивает отображение элементов управления и обеспечивает единообразный стиль для всех цветовых палитр.

### Разные размеры

Компонент поддерживает три размера, которые можно задать через свойство `size`:
- small – компактный размер (по умолчанию)
- medium – стандартный размер
- large – увеличенный размер

#### Компонент небольшого размера

<Canvas name="Компонент небольшого размера" of={colorBoxStories.SizeSmall} />
