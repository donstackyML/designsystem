# MeTimeRange

Компонент `me-time-range` предназначен для выбора временного диапазона с возможностью настройки начала и конца периода, шага и интервала обновления. Компонент поддерживает абсолютный и относительный режимы выбора времени.

<Controls of={timeRangeStories.Default} />

## Установка

Компонент `me-time-range` является standalone компонентом Angular. Для его использования нужно добавить компонент в массив импортируемых зависимостей

**Импортируйте компонент в ваш компонент**:
В файле вашего Angular компонента добавьте импорт `MeTimeRangeComponent`:

```typescript
import { MeTimeRangeComponent } from '@monitel/dx-monitel-components';
```

  [showTitle]="true"

  [hasFooterCancelButton]="false"
  [settingsBlocks]="['quickFilter', 'shiftSettings', 'steps', 'result']"
  [defaultSettings]="defaultSettings"
  [settings]="settings"
  (closed)="onClosed()"
  (popupOnHidden)="onPopupHidden()"
  (timeRangeApplied)="onTimeRangeApplied($event)"
></me-time-range>

import { Component } from '@angular/core';
import { TimeRangeConfig } from 'path-to-time-range-models';

@Component({
  selector: 'me-time-range-popup-demo',

})
class TimeRangePopupDemoComponent {
  popupVisible = false;
  popupPosition = {
    at: 'left bottom',
    my: 'left top',
    of: '#buttonId',
    offset: { y: 6 },
  };

  defaultSettings: Partial<TimeRangeConfig> = { /* ... */ };
  settings: Partial<TimeRangeConfig> = { /* ... */ };

  constructor() {

    const config: Partial<TimeRangeConfig> = {
      absoluteDate: { start: new Date(), end: new Date() },
      startShift: { type: 'mixed', switchIsActive: true, switchEnabled: true, properties: [ { text: 'Секунды', key: 'seconds', enabled: true, value: -20 } /* ... more properties ... */ ] },
      endShift: { type: 'mixed', switchIsActive: true, switchEnabled: true, properties: [ { text: 'Секунды', key: 'seconds', enabled: false, value: 0 } /* ... more properties ... */ ] },
      step: { items: [], selectedUnitValue: 'minutes', unitDisplayExpr: 'text', unitValueExpr: 'id', numberValue: 5 },
      quickFilterId: 'last_1h',
      update: { items: [], selectedUnitValue: 'seconds', unitDisplayExpr: 'text', unitValueExpr: 'id', numberValue: 30 },
    };
    this.defaultSettings = config;
    this.settings = JSON.parse(JSON.stringify(config));
  }

  togglePopup(): void {
    this.popupVisible = !this.popupVisible;
  }

  onClosed(): void {
    this.popupVisible = false;
  }

  onPopupHidden(): void {

    this.popupVisible = false;
  }

  onTimeRangeApplied(appliedSettings: TimeRangeConfig) {
    console.log('Popup time range applied:', appliedSettings);
    this.settings = appliedSettings;
    this.popupVisible = false;
  }
}
  `}

## API

### Входные параметры (Inputs)

#### Конфигурация

| Имя | Тип | По умолчанию | Описание |
|-----|-----|-------------|----------|
| `settings` | `Partial<TimeRangeConfig>` | `{}` | Настройки временного диапазона |
| `defaultSettings` | `Partial<TimeRangeConfig>` | `{}` | Настройки по умолчанию |
| `settingsBlocks` | `Array<'quickFilter' \| 'shiftType' \| 'shiftSettings' \| 'steps' \| 'result'>` | `['quickFilter', 'shiftSettings', 'steps', 'result']` | Блоки настроек для отображения. `'shiftType'` - новый возможный блок. |
| `changesApplyMode` | `'onChange' \| 'onApply'` | `'onChange'` | Режим применения изменений |

#### Режим попапа

| Имя | Тип | По умолчанию | Описание |
|-----|-----|-------------|----------|
| `isPopup` | `boolean` | `false` | Использовать компонент в режиме попапа |
| `popupIsVisible` | `boolean` | `false` | Видимость попапа |
| `popupWidth` | `string` | `'auto'` | Ширина попапа (в storybook примерах часто '600px' или '400px') |
| `popupHeight` | `string` | `'auto'` | Высота попапа |
| `popupPosition` | `PositionAlignment \| PositionConfig` | `{ my: 'left top', at: 'left bottom' }` | Позиция попапа |
| `popupAnimation` | `{ hide?: AnimationConfig; show?: AnimationConfig }` | `{}` | Анимация попапа |

#### Заголовок и кнопки

| Имя | Тип | По умолчанию | Описание |
|-----|-----|-------------|----------|
| `showTitle` | `boolean` | `false` | Показывать заголовок |
| `title` | `string` | `''` | Текст заголовка |
| `hasHeaderCloseButton` | `boolean` | `false` | Показывать кнопку закрытия в заголовке |
| `hasFooterCancelButton` | `boolean` | `false` | Показывать кнопку отмены в футере |
| `disableApplyButton` | `boolean \| null` | `null` | Отключить кнопку применения |
| `disableResetButton` | `boolean \| null` | `null` | Отключить кнопку сброса |

#### Интервал обновления

| Имя | Тип | По умолчанию | Описание |
|-----|-----|-------------|----------|
| `intervalTime` | `number \| null` | `null` | Интервал обновления в миллисекундах |

### Выходные события (Outputs)

| Имя | Тип | Описание |
|-----|-----|----------|
| `timeRangeApplied` | `EventEmitter<TimeRangeConfig>` | Применение временного диапазона |
| `settingsChanged` | `EventEmitter<TimeRangeConfig>` | Изменение настроек |
| `timeRangeReset` | `EventEmitter<TimeRangeConfig>` | Сброс временного диапазона |
| `timeShiftChanged` | `EventEmitter<TimeShiftChangedOutput>` | Изменение сдвига времени |
| `closed` | `EventEmitter<void>` | Закрытие компонента |
| `popupOnHidden` | `EventEmitter<void>` | Скрытие попапа |
