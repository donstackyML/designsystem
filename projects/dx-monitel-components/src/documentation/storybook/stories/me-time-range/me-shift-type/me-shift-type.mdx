# MeShiftType

Компонент `me-shift-type` используется для выбора типа сдвига времени в компоненте `me-time-range`. Позволяет переключаться между различными типами сдвига времени.

### С несколькими опциями

<Story of={shiftTypeStories.WithMultipleOptions} />

<Source
  code={`
// Template
<me-shift-type
  [shiftTypes]="defaultShiftTypes"
  [currentShiftType]="currentShiftType"
  (valueChange)="onShiftTypeChange($event)"
></me-shift-type>

// Component
const defaultShiftTypes = [
  { id: 'current', text: 'Относительно текущего времени' },
  { id: 'absolute', text: 'Абсолютное время' },
  { id: 'mixed', text: 'Смешанный режим' },
];

currentShiftType = 'current';

onShiftTypeChange(shiftType: string) {
  this.currentShiftType = shiftType;
}
  `}
  language="typescript"
  dark
/>

## API

### Входные параметры (Inputs)

| Имя | Тип | По умолчанию | Описание |
|-----|-----|-------------|----------|
| `valueExpr` | `string` | `'id'` | Свойство для определения значения |
| `displayExpr` | `string` | `'text'` | Свойство для отображения текста |
| `shiftTypes` | `Array<{ id: string; text: string }>` | `[{ id: 'current', text: 'Относительно текущего времени' }]` | Массив типов сдвига |
| `currentShiftType` | `string` | `'filters[0]?.id'` | Текущее выбранное значение |

### Выходные события (Outputs)

| Имя | Тип | Описание |
|-----|-----|----------|
| `valueChange` | `EventEmitter<string>` | Событие изменения выбранного значения |
