# MeTimeRangeResult

# Компонент MeTimeRangeResult

Компонент для отображения результата выбора временного диапазона. Позволяет показать начальную и конечную даты с возможностью подсветки отдельных частей даты.

<Controls of={timeRangeResultStories.Default} />

## Примеры использования

- [Стандартное использование](#стандартное-использование)
- [С подсветкой частей даты](#с-подсветкой-частей-даты)
- [С пользовательским форматом](#с-пользовательским-форматом)

### Стандартное использование

<Story of={timeRangeResultStories.Default} />

<Source
  code={`
// Template
<me-time-range-result
  [startDate]="startDate"
  [endDate]="endDate"
></me-time-range-result>

// Component
startDate = new Date('2024-03-20T10:00:00');
endDate = new Date('2024-03-20T18:00:00');
  `}
  language="typescript"
  dark
/>
