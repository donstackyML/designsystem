# LoadPanel

## Директива MeLoadPanel

При директивы `MeLoadPanel` к элементу `dx-load-panel` приводит его внешний вид согласно дизайн-системе, добавляет новое свойство `size`, автоматически устанавливает затенение фона и дает возможность выбрать стиль и цветовую схему индикатора загрузки.

### Размер панели загрузки

Для изменения размера панели загрузки используйте параметр `size`. Возможные значения: `small`, `medium` и `large`.

<Source
  code={`<dx-load-panel
  meLoadPanel
  [size]="size"
></dx-load-panel>`}
  dark
  language="html"
/>

### Изменение стиля и цвета индикатора загрузки

Для изменения стиля и цвета индикатора загрузки используйте параметры `stylingMode` и `color`. Возможные значения стиля: `circle`, `line`. Возможные значения цвета: `accent`, `default`, `normal`.

<Source
  code={`<dx-load-panel
  meLoadPanel
  [stylingMode]="stylingMode"
  [color]="color"
></dx-load-panel>`}
  dark
  language="html"
/>

### Изменение текста панели

Для изменения текста панели загрузки используйте параметр `message`.

<Source
	code={`<dx-load-panel
  meLoadPanel
  [message]="message"
></dx-load-panel>`}
	dark
	language="html"
/>

### Скрытие панели при клике вне

Для скрытия панели загрузки при клике вне используйте параметр `hideOnOutsideClick`.

<Source
	code={`<dx-load-panel
  meLoadPanel
  [hideOnOutsideClick]="hideOnOutsideClick"
></dx-load-panel>`}
	dark
	language="html"
/>
