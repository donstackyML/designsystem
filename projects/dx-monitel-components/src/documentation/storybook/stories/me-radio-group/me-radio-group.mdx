# RadioGroup

## Директива `meRadioGroup`

Применение директивы `meRadioGroup` к элементу `dx-radio-group` приводит его внешний вид в соответствие с дизайн-системой, его размеры к значению `size="medium"` и предоставляет доступ к свойству `size`.

Для изменения размеров используйте параметр `size`. Есть три варианта: `small`, `medium` (*по умолчанию*), `large`.

### Структуры данных

Items - это массив объектов, который является простым способом передачи данных в компонент. Используйте его, когда вам не нужно передавать дополнительные свойства или использовать кастомный шаблон. Items лучше использовать, когда вам не нужно передавать никаких данных кроме текста элемента.

<Source
  code={`
const items = [
  {
    index: 1,
    text: 'Воздушные линии электропередачи',
  },
  {
    index: 2,
    text: 'Кабельные линии электропередачи',
  },
  {
    index: 3,
    text: 'Трансформаторные подстанции',
  },
];
`}
  language="typescript"
  dark
/>

DataSource - это массив объектов, который содержит дополнительные свойства, которые могут быть использованы в кастомном шаблоне. Используйте его, когда вам нужно передать дополнительные свойства или использовать кастомный шаблон. DataSource лучше использовать, когда вам нужно передать дополнительные данные, такие как иконки, или использовать кастомный шаблон.
