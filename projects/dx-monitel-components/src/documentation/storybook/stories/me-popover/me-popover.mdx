# Popover

## Директива `mePopover`

Применение директивы `mePopover` к компоненту `dx-popover` приводит его размеры к значению `size="medium"` (*32px*) из дизайн-системы, а также приводит отступы в соответствие с дизайн-системой. Кроме того, директива добавляет свойства `size` и `colorMode`, позволяющие настроить внешний вид поповера.

### Размеры поповера

Для изменения размеров используется свойство `size`. Возможные значения: `small`, `medium`, `large` (по умолчанию — `medium`).
<Source code={`<dx-popover mePopover size="small"></dx-popover>`} language="html" dark/>

### Цветовая схема поповера

Свойство `colorMode` позволяет выбрать цветовую тему поповера. Возможные значения: `'default'`, `'alternate'`, `'light'`, `'dark'`. По умолчанию используется `default`.
<Source code={`<dx-popover mePopover colorMode="default"></dx-popover>`} language="html" dark/>

### События показа и скрытия

Свойства `showEvent` и `hideEvent` определяют, при каком событии поповер будет показываться и скрываться. Например, можно установить оба события равными `"click"`, чтобы поповер открывался и закрывался по клику.

<Source code={`<dx-popover mePopover showEvent="click" hideEvent="click"></dx-popover>`} language="html" dark/>

### Добавление кнопок

Чтобы добавить кнопки (например, для подтверждения или отмены действия) в нижнюю панель поповера, используется тег `dxi-toolbar-item` внутри компонента `dx-popover`. Пример ниже показывает, как вставить две кнопки, используя виджет `dxButton` и дополнительные свойства, такие как `cssClass` для индивидуальной стилизации.

<Source code={`
<dx-popover mePopover>
  <ng-container *ngIf="showToolbarItems">
    <dxi-toolbar-item
      widget="dxButton"
      toolbar="bottom"
      location="after"
      cssClass="popover-accept-button"
      [options]="acceptButton">
    </dxi-toolbar-item>
    <dxi-toolbar-item
      widget="dxButton"
      toolbar="bottom"
      location="after"
      [options]="cancelButton">
    </dxi-toolbar-item>
  </ng-container>
</dx-popover>
`} language="html" dark/>

### Настраиваемость контента

Поповер предоставляет широкие возможности по настройке контента. Вы можете не только задать простой текст, но и использовать собственные шаблоны для заголовка и основного содержимого. Это позволяет интегрировать в поповер сложные пользовательские интерфейсы, включающие изображения, кнопки и даже динамически генерируемый контент.

#### Простой текст контента

Если не требуется сложная разметка, можно просто передать текст через шаблон с именем 'content':

<Source code={`
<dx-popover mePopover>
  <div *dxTemplate="let data of 'content'">Содержимое поповера</div>
</dx-popover>
`} language="html" dark/>

#### Кастомизация заголовка с использованием шаблона

Для более гибкой настройки заголовка используйте свойство `titleTemplate` вместе с директивой `dxTemplate` внутри компонента `dx-popover`. В этом примере заголовок заменяется пользовательским шаблоном, который может включать изображение и кнопку закрытия.

<Source code={`
<dx-popover
  mePopover
  [showTitle]="true"
  [title]="title"
>
  <!-- Пользовательский шаблон заголовка -->
  <div *dxTemplate="let data of 'title'">
    <div class="title-wrapper">
      <div class="title-template-wrapper">
        <div class="title-template-image"></div>
        <dx-button
          meButton
          [size]="size"
          stylingMode="text"
          buttonType="normal"
          iconOnly="close"
        ></dx-button>
      </div>
      <h3 class="me-title-header1" style="margin: 0;">
        {{ titleTemplate }}
      </h3>
    </div>
  </div>
  <!-- Стандартный шаблон контента -->
  <div *dxTemplate="let data of 'content'">
    {{ content }}
  </div>
</dx-popover>
`} language="html" dark/>

Также обратите внимание на возможность стилизации пользовательских шаблонов через CSS. Пример ниже демонстрирует, как задать стили для элементов заголовка:

<Source code={`
.title-wrapper {
  display: flex;
  flex-direction: column;
  gap: 16px;
}
.title-template-wrapper {
  display: flex;
  justify-content: space-between;
  align-items: flex-start;
  gap: 16px;
}
.title-template-image {
  width: 216px;
  height: 125px;
  background: linear-gradient(135deg, #ff8a00 0%, #9c4dff 50%, #4a7dff 100%);
  border-radius: 3px;
}
.me-title-header1 {
  color: var(--popover-color);
}
`} language="css" dark/>

#### Пример комплексной настройки контента с панелью инструментов

В данном примере демонстрируется полный кастомизированный поповер, где вместо стандартного заголовка используется пользовательский шаблон (с изображением и кнопкой закрытия), а также добавлена панель инструментов с кнопками действий. Такой подход позволяет создать полностью индивидуальный интерфейс для уведомлений или подтверждений.

<Source code={`
<dx-popover
  mePopover
  [showTitle]="true"
  [title]="title"
>
  <!-- Кастомный шаблон заголовка -->
  <ng-container *ngIf="titleTemplate">
    <div *dxTemplate="let data of 'title'">
      <div class="title-wrapper">
        <div class="title-template-wrapper">
          <div class="title-template-image"></div>
          <dx-button
            meButton
            [size]="size"
            stylingMode="text"
            buttonType="normal"
            iconOnly="close"
          ></dx-button>
        </div>
        <h3 class="me-title-header1" style="margin: 0;">
          {{ titleTemplate }}
        </h3>
      </div>
    </div>
  </ng-container>
  <!-- Стандартный шаблон контента -->
  <div *dxTemplate="let data of 'content'">
    {{ content }}
  </div>
  <!-- Панель инструментов -->
  <ng-container *ngIf="showToolbarItems">
    <dxi-toolbar-item toolbar="bottom" location="after">
      <dx-button
        meButton
        [text]="acceptButton.text"
        [size]="size"
        stylingMode="filled"
        buttonType="default"
        (click)="acceptButton.onClick()"
      ></dx-button>
    </dxi-toolbar-item>
    <dxi-toolbar-item toolbar="bottom" location="after">
      <dx-button
        meButton
        [text]="cancelButton.text"
        [size]="size"
        stylingMode="filled"
        buttonType="normal"
        (click)="cancelButton.onClick()"
      ></dx-button>
    </dxi-toolbar-item>
  </ng-container>
</dx-popover>
`} language="html" dark/>
