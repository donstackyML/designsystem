# Menu

## Директива `meMenu`

Директива `meMenu` применяется к элементу `dx-menu` и стилизует его в соответствии с требованиями дизайн-системы. По умолчанию устанавливается размер `large`. Компонент поддерживает гибкую настройку ориентации, режимов выделения и поведения подменю.

### Режимы показа подменю

*Меню поддерживает различные режимы отображения подменю, которые задаются через свойства `showFirstSubmenuMode` и `showSubmenuMode`. Ниже приведены два варианта: показ подменю по клику и по наведению.*

#### Подменю по клику

*При установке режима `onClick` подменю показывается при клике на пункт меню. Для этого передаются объекты с настройками задержки отображения и скрытия подменю.*

<Canvas name="Подменю по клику" of={menuStories.ShowSubMenuModeOnClick} />

<Source
  language="html"
  dark
  code={`
<dx-menu
  meMenu
  [dataSource]="dataSource"
  [showFirstSubmenuMode]="{ name: 'onClick', delay: { show: 50, hide: 300 } }"
  [showSubmenuMode]="{ name: 'onClick', delay: { show: 50, hide: 300 } }"
>
</dx-menu>
`}
/>

#### Подменю по наведению

*Режим `onHover` позволяет показывать подменю при наведении курсора на элемент меню.*

<Canvas name="Подменю по наведению" of={menuStories.ShowSubMenuModeOnHover} />

<Source
  language="html"
  dark
  code={`
<dx-menu
  meMenu
  [dataSource]="dataSource"
  [showFirstSubmenuMode]="{ name: 'onHover', delay: { show: 50, hide: 300 } }"
  [showSubmenuMode]="{ name: 'onHover', delay: { show: 50, hide: 300 } }"
>
</dx-menu>
`}
/>

### Видимость разделителей

Свойство `dividersVisibility` определяет видимость разделителей в меню:

- `none` — разделители отсутствуют.
- `all` — разделители отображаются между всеми элементами.
- `auto` — разделители отображаются автоматически, в зависимости от данных.

#### Без разделителей

<Canvas name="DividersVisibilityNone" of={menuStories.DividersVisibilityNone} />
<Source
  code={`<dx-menu
  meMenu
  [dividersVisibility]="'none'"
  [dataSource]="dataSource">
</dx-menu>`}
  dark
  language="html"
/>

#### Все разделители

<Canvas name="DividersVisibilityAll" of={menuStories.DividersVisibilityAll} />
<Source

#### Добавление разделителей в элементы списка

Чтобы добавить разделитель между элементами списка, используйте свойство `hasDivider`. Если у элемента списка это свойство установлено в `true`, то после него будет добавлен разделитель.

Пример данных с использованием `hasDivider`:

<Canvas name="DividersVisibilityByContent" of={menuStories.WithGroupAndDividers} />
<Source
  code={`<dx-menu
  meMenu
  [dividersVisibility]="'auto'"
  [dataSource]="dataSource">
</dx-menu>

const dataSource = [
  {
    text: 'With groups',
    icon: argsIcon,
    hasDivider: true,
    items: [
      {
        text: 'Group Header Level 1',
        icon: iconStore.getIcon({ icon: 'public', size: 'size' }),
        disabled: true,
        beginGroup: true,
        hasDivider: true,
      },
      {
        text: 'Item 1',
        icon: argsIcon,
      },
      {
        text: 'Item 2',
        icon: argsIcon,
        items: [
          {
            text: 'Group Header Level 2',
            icon: iconStore.getIcon({ icon: 'public', size: 'size' }),
            disabled: true,
            beginGroup: true,
          },
          {
            text: 'Sub-item 1',
            icon: argsIcon,
          },
          {
            text: 'Sub-item 2',
            icon: argsIcon,
          },
        ],
      },
    ],
  },
];

`}
  dark
  language="html"
/>
