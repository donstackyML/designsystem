# Button

## Директива meButton

Применение директивы `meButton` к элементу `dx-button` приводит его размеры к значению `size = medium` (32px) из дизайн-системы и предоставляет доступ к другим свойствам.

Документация на сайте разработчика DevExtreme:

- <a href="https://js.devexpress.com/Angular/Documentation/ApiReference/UI_Components/dxButton/api/" target="_blank">API</a>
- <a href="https://js.devexpress.com/Angular/Demos/WidgetsGallery/Demo/Button/Overview/Light/" target="_blank">Демо</a>
