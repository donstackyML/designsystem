# SelectBox

## Директива `meSelectBox`

Применение директивы `meSelectBox` к компоненту `dx-select-box` приводит его размеры к значению `size="medium"` из дизайн-системы, а также приводит отступы в соответствие с дизайн-системой, добавляет свойство `size`.

### Размеры компонента

Изменение размера текстового поля влияет на отступы, размер шрифта и общую компоновку. Свойство `size` принимает три значения:
- small – уменьшенный размер, подходит для компактных интерфейсов;
- medium – стандартный размер (используется по умолчанию);
- large – увеличенный размер, удобен для форм с более крупным текстом.

### Разные режимы положения лейбла

Директива `meSelectBox` позволяет настраивать отображение лейбла с помощью свойства `labelMode`. Это свойство определяет, как и где будет отображаться метка поля, что может помочь улучшить читаемость формы и соответствовать требованиям макета.

#### Лейбл внешний

При значении `labelMode="outside"` лейбл располагается вне поля ввода. Такой вариант часто используется для четкого отделения метки от контрола.

<Canvas name="Лейбл внешний" of={selectBoxStories.LabelModeOutside} />

<Source
  code={`<dx-select-box meSelectBox labelMode="outside" label="Label"></dx-select-box>`}
  language="html"
  dark
/>

#### Лейбл статичный

Режим `labelMode="static"` фиксирует положение лейбла, не изменяя его при взаимодействии с полем. Это полезно, если требуется постоянное отображение метки в одном месте.

<Canvas name="Лейбл статичный" of={selectBoxStories.LabelModeStatic} />

<Source
  code={`<dx-select-box meSelectBox labelMode="static" label="Label"></dx-select-box>`}
  language="html"
  dark
/>

#### Лейбл всплывающий

При использовании `labelMode="floating"` лейбл будет перемещаться, когда поле получает фокус. Это создает эффект «плавающего» заголовка, позволяющий экономить пространство внутри поля ввода.

<Canvas name="Лейбл всплывающий" of={selectBoxStories.LabelModeFloating} />

<Source
  code={`<dx-select-box meSelectBox labelMode="floating" label="Label"></dx-select-box>`}
  language="html"
  dark
/>

#### Лейбл невидимый

Если необходимо скрыть метку (например, при использовании вспомогательных элементов или когда метка выводится иным способом), установите `labelMode="hidden"`. В этом режиме лейбл не отображается в интерфейсе.

<Canvas name="Лейбл невидимый" of={selectBoxStories.LabelModeHidden} />

<Source
  code={`<dx-select-box meSelectBox labelMode="hidden" label="Label"></dx-select-box>`}
  language="html"
  dark
/>

### Изменение положения лейбла с помощью директивы meLabel

Для вывода лейбла вне текстового поля можно использовать директиву `meLabel`. Это позволяет разместить метку отдельно от самого поля, задавая её положение с помощью свойства `labelDirection`.

#### Положение лейбла сверху

Чтобы лейбл располагался над текстовым полем, оберните компонент в контейнер с директивой `meLabel` и установите `labelDirection="column"`. Это позволяет создать вертикальное расположение, где метка находится сверху, а само поле — под ней.

<Canvas name="Лейбл сверху" of={selectBoxStories.WithLabelColumn} />

<Source
  code={`
<div meLabel labelDirection="column">
  <span>Label</span>
  <dx-select-box meSelectBox labelMode="hidden"></dx-select-box>
</div>
`}
  language="html"
  dark
/>

#### Положение лейбла слева

Чтобы разместить лейбл слева от текстового поля, используйте `labelDirection="row"`. Для корректного выравнивания задайте фиксированную ширину контейнера, например, через атрибут `width`.

<Canvas name="Лейбл слева" of={selectBoxStories.WithLabelRow} />

<Source
  code={`
<div meLabel labelDirection="row">
  <span>Label</span>
  <dx-select-box meSelectBox labelMode="hidden"></dx-select-box>
</div>
`}
  language="html"
  dark
/>

### Состояния readOnly и disabled

Свойства `readOnly` и `disabled` позволяют управлять интерактивностью текстового поля. В режиме readOnly поле становится доступным для копирования, но редактирование невозможно, а в режиме disabled поле полностью неактивно и выглядит затенённым.

### Видимость разделителей

Свойство `dividersVisibility` определяет видимость разделителей в выпадающем меню:

- `none` — разделители отсутствуют.
- `all` — разделители отображаются между всеми элементами.
- `auto` — разделители отображаются автоматически, в зависимости от данных.

#### Без разделителей

<Canvas name="DividersVisibilityNone" of={selectBoxStories.DividersVisibilityNone} />
<Source
  code={`<dx-select-box
  meSelectBox
  [dividersVisibility]="'none'"
  [dataSource]="dataSource">
</dx-select-box>`}
  dark
  language="html"
/>

#### Все разделители

<Canvas name="DividersVisibilityAll" of={selectBoxStories.DividersVisibilityAll} />
<Source
  code={`<dx-select-box
  meSelectBox

  [dataSource]="dataSource">
</dx-select-box>`}
  dark
  language="html"
/>

Чтобы добавить разделитель между элементами списка, используйте свойство `hasDivider`. Если у элемента списка это свойство установлено в `true`, то после него будет добавлен разделитель.

### Кастомные данные

Для использования кастомных данных используйте `dxTemplate` внутри тэга основного компонента.

<Source code={`
<dx-select-box
  [dataSource]="products">
  <div dxTemplate="let data of 'field'">
    <div class="custom-item">
      <img alt="Product name" src="{{ data && data.ImageSrc }}" />
      <div> {{ data && data.Name }} </div>
    </div>
  </div>
</dx-select-box>
`} dark language="html" />
