# ProgressBar

## Директива `meProgressBar`

Применение директивы `meProgressBar` к элементу `dx-progress-bar` приводит его внешний вид в соответствие с дизайн-системой, его размеры к значению `size="medium"` и предоставляет доступ к свойству `size`.

### Размеры компонента

Для изменения размеров используйте параметр `size`. Есть два варианта: `small`, `medium` (по умолчанию).

#### Размер маленький

<Canvas of={progressBarStories.SizeSmall} />

<Source
  code={`
 <dx-progress-bar
  meProgressBar
  [(value)]="value"
  size="small"
>
`}
  dark
  language="html"
/>

#### Размер средний

### Статус прогресса

По умолчанию компонент `dx-progress-bar` отображает статус прогресса. Для того чтобы отключить его отображение используйте свойство `showStatus="false"`.

<Canvas of={progressBarStories.WithoutTextStatus} />

<Source
  code={`<dx-progress-bar meProgressBar [showStatus]="false"></dx-progress-bar>`}
  dark
  language="html"
/>

### Заголовок в прогрессбаре

Компонент `dx-progress-bar` не поддерживает добавление заголовка, поэтому заголовок создается и стилизуется отдельно как в примере.

#### Заголовок в прогрессбаре маленький

<Canvas of={progressBarStories.WithHeaderSizeSmall} />
<Source
  code={`
<div class="form">
  <div class="me-progress-bar-header me-text-body2">Time left 00:00:10</div>
  <dx-progress-bar
    meProgressBar
    #progressBar
    id="progress-bar-status"
    [(value)]="value"
    size="small"
  >
  </dx-progress-bar>
</div>
`}
  dark
  language="html"
/>

<Source
  code={`

  text-align: center;

  text-align: center;
}

  width: 100%;
}
