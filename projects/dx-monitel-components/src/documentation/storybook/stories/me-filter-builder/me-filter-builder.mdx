# Filter Builder

Компонент `me-filter-builder` предназначен для построения фильтров по множеству полей с возможностью применения их к связанным компонентам отображения данных, таким как dx-data-grid и dx-list.

### Источники данных

#### Шаблоны редакторов (editorTemplate)

Каждое поле может использовать свой шаблон редактора для ввода значения:

- `textTemplate` — обычное текстовое поле
- `numberTemplate` — числовое поле
- `dateTemplate` — выбор даты
- `selectTemplate` — выпадающий список (нужен `selectBoxSources`)

Пример:

```ts
{
  dataField: 'HireDate',
  dataType: 'datetime',
  editorTemplate: 'dateTemplate',
}
```

#### Событие filteredValueChange

Для полей с шаблоном `selectTemplate` необходимо явно указать список возможных значений через объект `selectBoxSources`. Без этого список не будет отображаться.

Пример:

```ts
fields = [
  {
    dataField: 'Department',
    dataType: 'string',
    editorTemplate: 'selectTemplate',
  },
];
selectBoxSources = {
  Department: ['HR', 'Finance', 'Engineering', 'Marketing'],
};
```

#### Формат filteredValue

Значение `filteredValue` — это структура фильтра в формате DevExtreme.

Пример:

```ts
[
  ['Department', '=', 'Engineering'],
  'and',
  ['Salary', '>', 100000],
]
```

### Использование с компонентом Data Grid

Компонент `me-filter-builder` можно связать с DevExtreme `dx-data-grid`, чтобы применять построенный фильтр к таблице данных с помощью свойства `filterValue`.

<Canvas name="С фильтрацией таблицы (DataGrid)" of={filterBuilderStories.WithDataGrid} />

<Source
  dark
  language="html"
  code={`
<me-filter-builder
  [fields]="fields"
  [(filteredValue)]="filteredValue"
></me-filter-builder>

<dx-data-grid 
  style="margin-top: 20px;"
  [dataSource]="dataSource" 
  [filterValue]="filteredValue" 
  [showBorders]="true" 
  [columns]="fields"
></dx-data-grid>
`}
  
/>

### Использование с компонентом List

Для `dx-list` фильтрация происходит вручную через `DataSource`.

Особенности фильтрации в dx-list
В отличие от dx-data-grid, компонент dx-list не применяет фильтр автоматически. Он не поддерживает свойство filterValue, поэтому мы используем DataSource вручную:

```ts
const listDataSource = new DataSource({
store: {
  type: 'array',
  data: employeesDataList,
},

filteredValueChange: (val) => {
  listDataSource.filter(val);
  listDataSource.load();
}
});
```

<Canvas name="Фильтрация в List" of={filterBuilderStories.WithList} />

<Source
  dark
  language="html"
  code={`\
<me-filter-builder 
  [(filteredValue)]="filteredValue"
  (filteredValueChange)="filteredValueChange($event)"
></me-filter-builder>

<dx-list 
  style="margin-top: 20px;"
  meList 
  [dataSource]="listDataSource"
  [filter]="filteredValue"
  displayExpr="Name"
></dx-list>
`}
/>

- small – малый размер
- medium – средний размер
- large – увеличенный размер
