### Добавление описания в заголовок группы

Этот пример демонстрирует группировку элементов. Чтобы группировать, необходимо установить свойство `grouped="true"`. Переопределение шаблона группы через `dxTemplate` c именем `'group'` и позволяет добавить описание группы (например, `group.description`).
Также можно использовать свойство `collapsibleGroups` для создания сворачивающихся групп.
Подробнее порядок группировки описан в [разделе Grouping](https://js.devexpress.com/Angular/Documentation/Guide/UI_Components/List/Grouping/In_the_Data_Source/) для компонента List.

<Canvas name="Добавление описания в заголовок группы" of={listStories.ContentWithCustomTemplateForHeader} />

<Source
  code={`
<dx-list
  meList
  [dataSource]="dataSource"
  displayExpr="name"
  [grouped]="true"
  [collapsibleGroups]="true"
  searchExpr="name"
  width="436px"
>
  <!-- Пользовательский шаблон заголовка группы -->
  <div *dxTemplate="let group of 'group'">
    <p class="me-title-header2" style="margin: 0">{{ group.key }}</p>
    <p class="me-text-caption" style="margin: 0">{{ group.description }}</p>
  </div>
</dx-list>

// Пример dataSource:
const dataSource = [
  {
    key: 'Fruits',
    description: 'Описание фруктов',
    items: [
      { name: 'Apples', count: 10 },
      { name: 'Oranges', count: 12 },
      { name: 'Lemons', count: 15 },
    ],
  },
  {
    key: 'Vegetables',
    description: 'Описание овощей',
    items: [
      { name: 'Potatoes', count: 5 },
      { name: 'Tomatoes', count: 9 },
      { name: 'Turnips', count: 8 },
    ],
  },
];
  `}
  language="typescript"
  dark
/>

### Добавление описания и картинки в элемент списка

Здесь для каждого элемента списка используется пользовательский шаблон (`dxTemplate`) c именем `'item'`, который добавляет изображение и описание. Это позволяет обогатить стандартный вывод данных, сделав каждый пункт более информативным.

Этот пример демонстрирует использование пользовательского шаблона для передачи дополнительной информации о каждом элементе. Переопределение шаблона группы через `dxTemplate` c именем `'item'`.
Подробнее порядок группировки описан в [разделе CustomizeItemAppearance](https://js.devexpress.com/Angular/Documentation/Guide/UI_Components/List/Customize_Item_Appearance/) для компонента List.

<Canvas name="Добавление описания и картинки в элемент списка" of={listStories.ContentWithCustomTemplateForListItem} />
<Source
  code={`
<dx-list
  meList
  [dataSource]="dataSource"
  displayExpr="name"
  width="436px"
>
  <!-- Пользовательский шаблон для элемента списка -->
  <div *dxTemplate="let item of 'item'">
    <div class="me-list-item-content">
      <img alt="{{ item.name }}" src="{{ item.image }}" />
      <div>
        <div class="me-text-body2">{{ item.name }}</div>
        <div class="me-text-caption">{{ item.description }}</div>
      </div>
    </div>
  </div>
</dx-list>

// Пример dataSource:
const dataSource = [
  {
    name: 'Apples',
    image: '../../../assets/images/image.png',
    description: 'Описание для яблок.',
  },
  {
    name: 'Oranges',
    image: '../../../assets/images/image.png',
    description: 'Описание для апельсинов.',
  },
  {
    name: 'Lemons',
    image: '../../../assets/images/image.png',
    description: 'Описание для лимонов.',
  },
];
  `}
  language="typescript"
  dark
/>

### Работа с иконками

В этом примере показано, как использовать иконки в элементах списка. Сначала необходимо подключить сервис иконок (например, через `iconStore.getIcon`), а затем передать полученную иконку в свойство `icon` элемента данных. Можно также задать цвет иконки с помощью свойства `color` в объекте опций.

<Canvas name="Работа с иконками" of={listStories.ContentWithIcons} />

<Source
  code={`
/ Пример использования иконок в данных списка /
public itemsWithIcons: Item[] = [
  {
    name: 'Apples',
    icon: iconStore.getIcon({ icon: 'check', size: '24', color: '#4caf50' }),
  },
  // другие элементы...
];

// В шаблоне:
<dx-list
  meList
  [dataSource]="itemsWithIcons"
  displayExpr="name">
</dx-list>
  `}
  dark
  language="js"
/>

### Видимость разделителей

Свойство `dividersVisibility` определяет видимость разделителей у элементов списка в выпадающем меню:

- `none` — разделители отсутствуют.
- `all` — разделители отображаются между всеми элементами.
- `auto` — разделители отображаются автоматически, в зависимости от данных.

#### Без разделителей

<Canvas name="DividersVisibilityNone" of={listStories.DividersVisibilityNone} />
<Source
  code={`<dx-list
  meList
  [dividersVisibility]="'none'"
  [items]="items">
</dx-list>`}
  dark
  language="html"
/>

#### Все разделители

<Canvas name="DividersVisibilityAll" of={listStories.DividersVisibilityAll} />
<Source
  code={`<dx-list
  meList
  [dividersVisibility]="'all'"
  [items]="items">
</dx-list>`}
  dark
  language="html"
/>

#### Перетаскивание элементов (Reordering)

С помощью опции перетаскивания (`dxo-item-dragging` с `allowReordering="true"`) можно разрешить пользователю изменять порядок элементов в списке, что удобно для настройки приоритетов или сортировки.

<Canvas name="Перетаскивание элементов" of={listStories.WithReordering} />

<Source
  code={`

  <dxo-item-dragging [allowReordering]="true"></dxo-item-dragging>
</dx-list>
  `}
  dark
  language="html"
/>
