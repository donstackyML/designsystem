# DropDownBox

## Директива `meDropDownBox`

Директива `meDropDownBox` применяется к компоненту `dx-drop-down-box` для кастомизации его внешнего вида и поведения в соответствии с дизайн-системой. Она добавляет поддержку размеров (small, medium, large), настраивает отображение скролла, добавляет возможность вставки иконки слева и обеспечивает правильную работу с TreeView и DataGrid внутри.

### Размеры компонента

Компонент поддерживает три размера, которые можно задать через свойство `size`:
- small – компактный размер
- medium – стандартный размер (по умолчанию)
- large – увеличенный размер

#### Компонент небольшого размера

### С TreeView внутри

Компонент может содержать TreeView для выбора элементов в иерархическом виде.

<Canvas name="С TreeView внутри" of={dropDownBoxStories.WithTreeView} />

<Source
  code={`<dx-drop-down-box
  meDropDownBox
  [dataSource]="dataSource"
  displayExpr="name"
  valueExpr="id"
>
  <dx-tree-view
    meTreeView
    [dataSource]="dataSource"
    dataStructure="plain"
    keyExpr="id"
    parentIdExpr="categoryId"
    selectionMode="multiple"
    showCheckBoxesMode="normal"
    [selectNodesRecursive]="false"
    displayExpr="name"
    [selectByClick]="true"
  >
  </dx-tree-view>
</dx-drop-down-box>`}
  language="html"
  dark
/>

### С DataGrid внутри

Для выбора элементов из таблицы можно использовать DataGrid внутри DropDownBox.

<Canvas name="С DataGrid внутри" of={dropDownBoxStories.WithDataGrid} />

<Source
  code={`<dx-drop-down-box
  meDropDownBox
  [dataSource]="dataSource"
  displayExpr="name"
  valueExpr="id"
>
  <dx-data-grid
    meDataGrid
    [dataSource]="dataSource"
    [columns]="['id', 'name']"
    [selection]="{ mode: 'multiple' }"
    [hoverStateEnabled]="true"
    [filterRow]="{ visible: true }"
    [height]="300"
  >
  </dx-data-grid>
</dx-drop-down-box>`}
  language="html"
  dark
/>

### Настройка скролла

Свойство `showScrollbar` определяет поведение скролла в выпадающем списке:
- `always` - скролл отображается всегда
- `onHover` - скролл отображается только при наведении

#### Скролл всегда видим

<Canvas name="Скролл всегда видим" of={dropDownBoxStories.ScrollbarAlways} />

<Source
  code={`<dx-drop-down-box
  meDropDownBox
  showScrollbar="always"
></dx-drop-down-box>`}
  language="html"
  dark
/>

#### Скролл при наведении
