# Breadcrumbs

Компонент `me-breadcrumbs` предоставляет навигационную цепочку для отображения текущего местоположения пользователя в иерархии сайта. Он улучшает пользовательский опыт, позволяя легко ориентироваться по структуре приложения.

## С иконками

Добавление иконок к элементам хлебных крошек для улучшения визуального восприятия:

<Canvas of={breadcrumbsStories.WithIcons} />

<Source
  code={`
<me-breadcrumbs
  [items]="breadcrumbsItems"
></me-breadcrumbs>
  `}
  dark
  language="html"
/>

## Направление сокращения хлебных крошек

### Сокращение справа

По умолчанию, при нехватке места элементы сокращаются справа.

<Canvas of={breadcrumbsStories.TruncateFromRight} />
<Source
  code={`
<me-breadcrumbs
  [items]="breadcrumbsItems"
></me-breadcrumbs>
  `}
  dark
  language="html"
/>

### Сокращение слева

По умолчанию, при нехватке места элементы сокращаются справа. Вы можете изменить это поведение, установив свойство `truncateFrom="left"`:

<Canvas of={breadcrumbsStories.TruncateFromLeft} />
<Source
  code={`
<me-breadcrumbs
  [items]="breadcrumbsItems"
  truncateFrom="left"
></me-breadcrumbs>
  `}
  dark
  language="html"
/>

## Обработка событий

Компонент `MeBreadcrumbs` поддерживает событие `itemClick` для обработки кликов по элементам:

<Source
  code={`
<me-breadcrumbs
  [items]="breadcrumbsItems"
  (itemClick)="onBreadcrumbItemClick($event)"
></me-breadcrumbs>
  `}
  dark
  language="html"
/>
