# Breadcrumbs

Компонент `me-breadcrumbs` предоставляет навигационную цепочку для отображения текущего местоположения пользователя в иерархии сайта. Он улучшает пользовательский опыт, позволяя легко ориентироваться по структуре приложения.

### Обработка событий

При клике по элементу хлебных крошек срабатывает событие `itemClick`, типом для `$event` является `BreadcrumbItem`. Это позволяет получить детальную информацию о нажатом элементе, например, его текст или ссылку.

<Source
  code={`
<me-breadcrumbs
  [items]="breadcrumbsItems"
  (itemClick)="onBreadcrumbItemClick($event)">
</me-breadcrumbs>

// В вашем компоненте:
// Тип $event: BreadcrumbItem
onBreadcrumbItemClick(event: BreadcrumbItem) {
  console.log('Нажат элемент:', event);
}
  `}
  dark
  language="html"
/>

### Кастомные названия полей

Если структура передаваемых данных отличается от стандартной (например, вместо `text`, `icon`, `items`, `url` используются `name`, `iconData`, `links`, `link`), вы можете настроить компонент с помощью следующих свойств:

- **displayExpr** — имя поля для отображения текста. По умолчанию: `"text"`.
- **iconExpr** — имя поля для отображения иконки. По умолчанию: `"icon"`.
- **itemsExpr** — имя поля для вложенных элементов. По умолчанию: `"items"`.
- **urlExpr** — имя поля для ссылки. По умолчанию: `"url"`.

Пример использования с кастомными названиями полей:

<Canvas of={breadcrumbsStories.WithCustomFields} />

<Source
  code={`
<me-breadcrumbs
  [items]="[
    {
      name: 'Главная',
      link: '/',
      iconData: 'home'
    },
    {
      name: 'Продукты',
      link: '/products',
      iconData: 'shop',
      links: [
        {
          name: 'Электроника',
          link: '/products/electronics',
          iconData: 'tv'
        }
      ]
    }
  ]"
  displayExpr="name"
  iconExpr="iconData"
  itemsExpr="links"
  urlExpr="link"
></me-breadcrumbs>
  `}
  dark
  language="html"
/>
