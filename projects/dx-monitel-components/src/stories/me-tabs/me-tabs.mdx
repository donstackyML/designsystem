# Tabs

> ## Директива meTabs
>
> Директива `meTabs` стилизует компонент `dx-tabs` в соответствии с дизайн-системой, добавляя поддержку различных размеров и стилей отображения.

<Canvas of={tabsStories.Default} />
<Controls of={tabsStories.Default} />

## Примеры использования

### Базовые вкладки

```html
<dx-tabs
  meTabs
  [dataSource]="tabs"
  [size]="'medium'"
  [stylingMode]="'inside'"
>
</dx-tabs>
```

### Структура данных

```typescript
import {registry} from "./preview";
import {mailX20} from "./-mail_x20.icon";
import {publicX20} from "./-public_x20.icon";
interface Tab {
  id: number;
  text: string;
  icon?: string;
  disabled?: boolean;
}

const tabs = [
  {
    id: 1,
    text: 'Tab 1',
    icon: registry.getIcon(publicX20)
  },
  {
    id: 2,
    text: 'Tab 2',
    icon: registry.getIcon(mailX20)
  }
];
```

## API Reference

### Основные параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|-----------|
| size | 'small' \| 'medium' \| 'large' | 'medium' | Размер вкладок |
| position | 'top' \| 'bottom' | 'top' | Позиция вкладок |
| stylingMode | 'inside' \| 'outside' | 'inside' | Стиль отображения |
| orientation | 'horizontal' \| 'vertical' | 'horizontal' | Ориентация вкладок |
| iconPosition | 'top' \| 'start' \| 'end' \| 'bottom' | 'start' | Позиция иконок |
| width | string \| number | 'auto' | Ширина компонента |

### Поведение

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|-----------|
| showNavButtons | boolean | false | Кнопки навигации |
| scrollByContent | boolean | false | Прокрутка содержимым |
| rtlEnabled | boolean | false | Поддержка RTL |
| hoverStateEnabled | boolean | true | Эффект наведения |

### События

- `onItemClick` - клик по вкладке
- `onSelectionChanged` - изменение выбора
- `onItemRendered` - после рендера вкладки

### Стилизация

```css
/* Стили вкладок */
.dx-tabs {
  --me-tabs-item-padding: 8px 16px;
  --me-tabs-item-gap: 8px;
  --me-tabs-border-radius: 4px;
}

/* Активная вкладка */
.dx-tab-selected {
  --me-tabs-selected-bg: var(--Primary-Main);
  --me-tabs-selected-color: white;
}
```
