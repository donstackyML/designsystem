### Календарь без номеров недель

Чтобы скрыть номера недель, используйте параметр `showWeekNumbers={false}`.

<Story name="WithoutWeekNumbers" of={calendarStories.WithoutWeekNumbers} />

<Source
  code={`<dx-calendar meCalendar [showWeekNumbers]="false"></dx-calendar>`}
  dark
  language="html"
/>

### Нумерация недель

В некоторых случаях может потребоваться настроить, как именно отображаются номера недель в календаре. Это может зависеть от региональных стандартов или специфики вашего проекта. Для этого предусмотрена настройка правила нумерации с помощью параметра `weekNumberRule`. Доступны следующие варианты:

#### Вариант `firstDay`

Вариант `firstDay` определяет номер недели, исходя из первого дня недели, установленного в календаре.

<Story name="WeekNumberRuleFirstDay" of={calendarStories.WeekNumberRuleFirstDay} />

<Source
  code={`<dx-calendar meCalendar [weekNumberRule]="'firstDay'"></dx-calendar>`}
  dark
  language="html"
/>

#### Вариант `firstFourDays`

При выборе варианта `firstFourDays` неделя будет присвоена тому месяцу, в котором содержится не менее четырех дней. Это позволяет учитывать ситуации, когда первые дни месяца распределены между двумя календарными неделями.

<Story name="WeekNumberRuleFirstFourDays" of={calendarStories.WeekNumberRuleFirstFourDays} />

<Source
  code={`<dx-calendar meCalendar [weekNumberRule]="'firstFourDays'"></dx-calendar>`}
  dark
  language="html"
/>

#### Вариант `fullWeek`

Вариант `fullWeek` предполагает, что неделя будет отображаться только в том случае, если она полностью входит в текущий месяц. Это может быть полезно для строгого разделения недель по месяцам.

<Story name="WeekNumberRuleFullWeek" of={calendarStories.WeekNumberRuleFullWeek} />

<Source
  code={`<dx-calendar meCalendar [weekNumberRule]="'fullWeek'"></dx-calendar>`}
  dark
  language="html"
/>

### Выбор даты

Календарь поддерживает несколько режимов выбора дат, которые позволяют реализовать различные сценарии работы с датами.

#### Режим одиночного выбора

В режиме одиночного выбора можно выбрать только одну дату.

<Story name="SelectionModeSingle" of={calendarStories.SelectionModeSingle} />

<Source
  code={`<dx-calendar meCalendar selectionMode="single"></dx-calendar>`}
  dark
  language="html"
/>

#### Режим множественного выбора

В режиме множественного выбора можно выбрать несколько дат одновременно.

<Story name="SelectionModeMultiple" of={calendarStories.SelectionModeMultiple} />

<Source
  code={`<dx-calendar meCalendar selectionMode="multiple"></dx-calendar>`}
  dark
  language="html"
/>

#### Выбор полной недели при клике

Чтобы при клике выделялась не отдельная дата, а целая неделя, используйте параметр `selectWeekOnClick` совместно с параметром `selectionMode="multiple"`. Это позволит выбрать всю неделю, нажав на ее номер.

<Story name="SelectFullWeekOnClick" of={calendarStories.SelectFullWeekOnClick} />

<Source
  code={`<dx-calendar meCalendar [selectWeekOnClick]="true"></dx-calendar>`}
  dark
  language="html"
/>

#### Режим выбора диапазона

В режиме выбора диапазона можно выбрать диапазон дат, например, для указания периода.

<Story name="SelectionModeRange" of={calendarStories.SelectionModeRange} />

<Source
  code={`<dx-calendar meCalendar selectionMode="range"></dx-calendar>`}
  dark
  language="html"
/>

Чтобы отключить календарь, используйте параметр `disabled={true}`.

<Source
  code={`<dx-calendar meCalendar [disabled]="true"></dx-calendar>`}
  dark
  language="html"

### Изменение первого дня недели

Для изменения первого дня недели используйте параметр `firstDayOfWeek`. Например, чтобы задать воскресенье в качестве первого дня недели:

<Story name="CustomFirstDay" of={calendarStories.CustomFirstDay} />

<Source
  code={`<dx-calendar meCalendar [firstDayOfWeek]="0"></dx-calendar>`}
  dark
  language="html"
/>

## Обработка событий

Календарь поддерживает стандартные события DevExtreme. Например, для обработки изменения выбранной даты:

<Source
  code={`
<dx-calendar
  meCalendar
  [value]="currentDate"
  (onValueChanged)="onDateValueChanged($event)"
></dx-calendar>

// В вашем компоненте:
onDateValueChanged(e: any) {
  console.log('Выбранная дата:', e.value);
}
`}
  dark
  language="typescript"
/>
