# TabPanel

> ## Директива meTabPanel
>
> Директива `meTabPanel` расширяет стандартный компонент `dx-tab-panel`, добавляя поддержку размеров и стилей из дизайн-системы.

<Canvas of={tabPanelStories.Default} />
<Controls of={tabPanelStories.Default} />

## Примеры использования

### Базовый TabPanel

```html
<dx-tab-panel
  meTabPanel
  [dataSource]="tabItems"
  [size]="'medium'"
  [styling]="'outside'"
>
  <div *dxTemplate="let item of 'item'">
    <div class="tabpanel-content">
      {{ item.content }}
    </div>
  </div>
</dx-tab-panel>
```

### Вертикальные вкладки

<Canvas of={tabPanelStories.VerticalTabs} />

```html
<dx-tab-panel
  meTabPanel
  [dataSource]="tabItems"
  [tabsPosition]="'left'"
  [height]="300"
>
</dx-tab-panel>
```

### Разные позиции иконок

<Canvas of={tabPanelStories.DifferentIconPositions} />

```html
<dx-tab-panel
  meTabPanel
  [dataSource]="tabItems"
  [iconPosition]="'top'"
>
</dx-tab-panel>
```

### Структура данных

```typescript
interface TabPanelItem {
  title: string;          // Заголовок вкладки
  icon: string;           // Иконка
  content: string;        // Содержимое
  disabled?: boolean;     // Отключение вкладки
  visible?: boolean;      // Видимость вкладки
}

const tabItems = [
  {
    title: 'To Do',
    icon: 'user',
    content: 'Content for To Do tab'
  },
  // ...
];
```

## API Reference

### Основные параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|-----------|
| size | 'small' \| 'medium' \| 'large' | 'medium' | Размер компонента |
| styling | 'inside' \| 'outside' | 'outside' | Стиль отображения |
| tabsPosition | 'top' \| 'bottom' \| 'left' \| 'right' | 'top' | Позиция вкладок |
| iconPosition | 'bottom' \| 'top' \| 'start' \| 'end' | 'start' | Позиция иконок |
| height | number \| string | 'auto' | Высота панели |
| width | number \| string | '100%' | Ширина панели |
| selectedIndex | number | 0 | Индекс активной вкладки |

### Состояния

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|-----------|
| disabled | boolean | false | Отключение компонента |
| activeStateEnabled | boolean | true | Состояние активности |
| focusStateEnabled | boolean | true | Состояние фокуса |
| hoverStateEnabled | boolean | true | Состояние наведения |
| swipeEnabled | boolean | false | Переключение свайпом |

### События

- `onSelectionChanged` - при смене вкладки
- `onTitleClick` - при клике на заголовок
- `onTitleHold` - при удержании заголовка
- `onTitleRendered` - после рендера заголовка

### Стилизация

#### CSS-классы

```css
/* Отступы контейнера */
.my-tabpanel .dx-tabpanel-container {
  padding: 20px;
}

/* Стили вкладок */
.my-tabpanel .dx-tab {
  padding: 10px 20px;
}

/* Активная вкладка */
.my-tabpanel .dx-tab-selected {
  background-color: #f0f0f0;
}
```

#### CSS-переменные

```css
.my-tabpanel {
  --me-tabpanel-container-padding: 20px;
  --me-tabpanel-tab-padding: 10px 20px;
  --me-tabpanel-selected-bg: #f0f0f0;
}
```
