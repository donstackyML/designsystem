# TabPanel

Компонент TabPanel представляет собой контейнер для отображения содержимого во вкладках.

<Canvas of={tabPanelStories.Default} />

## Свойства

<Controls />

## Использование

Для использования TabPanel в вашем приложении, примените директиву `meTabPanel` к компоненту `dx-tab-panel`:

<Source
  language="html"
  dark
  code={`
<dx-tab-panel
  meTabPanel
  [dataSource]="dataSource"
  [height]="height"
  [iconPosition]="iconPosition"
  [selectedIndex]="selectedIndex"
  [width]="width"
  [size]="size"
>
  <div *dxTemplate="let item of 'item'">
    <div class="tabpanel-content">
      <p>{{item.content}}</p>
    </div>
  </div>
</dx-tab-panel>
  `}
/>

## Кастомизация

### Внутренние отступы

По умолчанию контейнер TabPanel не имеет внутренних отступов. Вы можете добавить их через:

1. CSS-классы:
```css
.my-tabpanel .dx-tabpanel-container {
  padding: 20px;
}
```
2. CSS-переменную:

```css
  .my-tabpanel {
  --me-tabpanel-container-padding: 20px;
}
```
