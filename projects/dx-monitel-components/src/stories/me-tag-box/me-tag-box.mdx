# TagBox

## Директива meTagBox

Применение директивы meTagBox к элементу <code>dx-tagbox</code> приводит его размеры к значению <code>size=medium</code> из дизайн-системы, а также приводит отступы в соответствие
с дизайн-системой, добавляет свойство <code>size</code>.

### Размеры TagBox
Для изменения размеров используйте параметр `size`. Есть три варианта: `small`, `medium`, `large`.

<Source
			code={`<dx-tag-box meTagBox size="size"></dx-tag-box>`}
			language="html"
			dark
/>

### Положение Label
Для изменения положения Label используйте параметр `labelMode`. Есть три варианта: `static`, `floating`, `hidden`, `outside`. Для изменения самого Label внутри используйте параметр `label`

<Source
  code={`<dx-tag-box meTagBox labelMode="labelMode" label="label"></dx-tag-box>`}
  dark
  language="html"
/>

Для того, чтобы установить label слева от элемента, используйте тэг обертку `label` с директивой `meLabel` и параметром `labelDirection="row"`, установив параметр `labelMode="hidden"` в <code>meTagBox</code>.

<Source
			code={`
  <label meLabel 
  labelDirection="row">
    <dx-tag-box meTagBox labelMode="hidden"></dx-tag-box>
  </label>`}
	dark
	language="html"
/>
<Story name="Default" of={TagBoxStories.WithLabelRow} />

### Валидация поля
Для валидации используйте `<dx-validator>` внутри тэга `dx-tag-box`. Для добавления валидации используйте тэг `<dxi-validation-rule>` и параметры `type` и `message`.
Не забудьте импортировать `DxTextAreaModule` и `DxValidatorModule`.
Используйте параметры `validationMessageMode` для изменения режима отображения сообщения об ошибке. Варианты: `auto` и `always`.
Используйте параметр `validationMessagePosition` для изменения положения сообщения об ошибке. Варианты: `top`, `bottom`, `left`, `right`.

<Source
	code={`<dx-tag-box meTextArea
  [(validationMessageMode)]="validationMessageMode"
  [(validationMessagePosition)]="validationMessagePosition">
  <dx-validator>
    <dxi-validation-rule 
    type="required"
    message="Required"
    ></dxi-validation-rule>
  </dx-validator>
</dx-tag-box>`}
	dark
	language="html"
/>
