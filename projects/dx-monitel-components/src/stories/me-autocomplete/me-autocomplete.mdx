# Autocomplete

## Директива meAutocomplete

Применение директивы meAutocomplete к элементу <code>dx-autocomplete</code> приводит его размеры к значению <code>size=medium</code> из дизайн-системы, а также приводит отступы в соответствие
с дизайн-системой, добавляет свойство <code>size</code>.

### Размеры Autocomplete
Для изменения размеров используйте параметр `size`. Есть три варианта: `small`, `medium`, `large`.

<Source
			code={`<dx-autocomplete meAutocomplete size="size"></dx-autocomplete>`}
			language="html"
			dark
/>

### Положение Label
Для изменения положения Label используйте параметр `labelMode`. Есть три варианта: `static`, `floating`, `hidden`, `outside`. Для изменения самого Label внутри используйте параметр `label`

<Source
  code={`<dx-autocomplete meAutocomplete labelMode="labelMode" label="label"></dx-autocomplete>`}
  dark
  language="html"
/>

Для того, чтобы установить label слева от элемента, используйте тэг обертку `label` с директивой `meLabel` и параметром `labelDirection="row"`, установив параметр `labelMode="hidden"` в <code>meAutocomplete</code>.

<Source
			code={`
  <label meLabel 
  labelDirection="row">
    <dx-autocomplete meAutocomplete labelMode="hidden"></dx-autocomplete>
  </label>`}
	dark
	language="html"
/>
<Story name="Default" of={AutocompleteStories.WithLabelRow} />

### Валидация поля
Для валидации используйте `<dx-validator>` внутри тэга `dx-autocomplete`. Для добавления валидации используйте тэг `<dxi-validation-rule>` и параметры `type` и `message`.
Не забудьте импортировать `DxValidatorModule`.
Используйте параметры `validationMessageMode` для изменения режима отображения сообщения об ошибке. Варианты: `auto` и `always`.
Используйте параметр `validationMessagePosition` для изменения положения сообщения об ошибке. Варианты: `top`, `bottom`, `left`, `right`.

<Source
	code={`<dx-autocomplete meAutocomplete
  [(validationMessageMode)]="validationMessageMode"
  [(validationMessagePosition)]="validationMessagePosition">
  <dx-validator>
    <dxi-validation-rule 
    type="required"
    message="Required"
    ></dxi-validation-rule>
  </dx-validator>
</dx-autocomplete>`}
	dark
	language="html"
/>
