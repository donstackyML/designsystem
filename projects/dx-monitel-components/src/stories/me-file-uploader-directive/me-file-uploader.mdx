# FileUploader

Директива `meFileUploader` предоставляет стилизацию для компонента DxFileUploader в соответствии с дизайн-системой.

## Основные возможности

- Поддержка drag & drop
- Валидация типов файлов
- Отображение прогресса загрузки
- Множественная загрузка
- Отложенная загрузка с кнопками
- Загрузка файлов по частям
- Кастомная зона для drag & drop

## События

FileUploader поддерживает следующие основные события:

- `onUploadStarted` - начало загрузки файла
- `onUploaded` - файл успешно загружен
- `onProgress` - прогресс загрузки файла
- `onUploadError` - ошибка при загрузке
- `onValueChanged` - изменение выбранных файлов
- `onDropZoneEnter` - файл перетащен в зону загрузки
- `onDropZoneLeave` - файл убран из зоны загрузки

Пример обработки событий:

<Source
  code={`
<dx-file-uploader
  meFileUploader
  (onUploadStarted)="onUploadStarted($event)"
  (onUploaded)="onUploaded($event)"
  (onProgress)="onProgress($event)"
  (onUploadError)="onUploadError($event)"
>
</dx-file-uploader>

  // В компоненте
  onUploadStarted(e) {
    console.log('Upload started:', e);
  }

  onUploaded(e) {
    console.log('File uploaded:', e);
  }

  onProgress(e) {
    const progress = e.bytesLoaded / e.bytesTotal * 100;
    console.log('Upload progress:', progress);
  }

  onUploadError(e) {
    console.error('Upload error:', e);
  }
`}
  dark
  language="typescript"
/>
