# StatusBar

## Компонент `me-status-bar`

Компонент `me-status-bar` предназначен для отображения информационных сообщений и уведомлений в виде строки статуса. Он позволяет отображать текст, иконки и фоновые заливки в зависимости от типа статуса. С помощью данного компонента можно визуально выделить ошибки, предупреждения, успех или информационные сообщения в пользовательском интерфейсе.

## API

<Source
  code={`
type StatusType = 'error' | 'warning' | 'success' | 'info';

interface StatusBarItem {
  text: string;             // Текст элемента статуса
  textColor?: string;       // Цвет текста
  type?: StatusType;        // Тип статуса (error, warning, success, info)
  icon?: string;            // Название или путь к иконке
  iconColor?: string;       // Цвет иконки
  showStatusIcon?: boolean; // Отображать ли иконку, соответствующую типу статуса
  fill?: boolean;           // Использовать ли заливку фона за элементом
  backgroundColor?: string; // Цвет фона элемента
  readonly?: boolean;       // Режим только для чтения (элемент не кликабелен)
  onClick?: () => void;     // Обработчик клика по элементу
}
  `}
  dark
  language="typescript"
/>

### Статусы

#### Статус Error

Элемент статуса с типом **error** показывает сообщение об ошибке. В примере слева отображаются элементы статуса, а справа – сообщение об отсутствии соединения с источником данных, которое выделено красной заливкой и иконкой ошибки.

<Canvas name="Статус Error" of={statusBarStories.ErrorStatus} />

<Source
  code={`
<me-status-bar
  [leftItems]="[
      { text: 'Воткинская ГЭС', icon: 'home' },
      { text: 'Раскраска схемы без учета ТП', fill: true, type: 'info' },
      { text: 'Режим исследования', fill: true, type: 'warning' }
    ]"
  [rightItems]="[
    { icon: 'error', text: 'Отсутствует соединение с источником данных', fill: true, type: 'error' }
  ]"
  size="large"
  [showDivider]="true">
</me-status-bar>
  `}
  dark
  language="html"
/>

### Добавление иконок

#### Иконки соответствующие типу статусов

В этом примере компонент автоматически отображает стандартную иконку, соответствующую типу статуса, если задано свойство `showStatusIcon`.

<Canvas name="Иконки соответствующие типу статусов" of={statusBarStories.StatusIcons} />

<Source
  code={`
<me-status-bar
  [leftItems]="[{ text: 'Воткинская ГЭС' }]"
  [rightItems]="[
    { text: 'Отсутствует соединение с источником данных', type: 'error', showStatusIcon: true, fill: true }
  ]"
  size="large"
  [showDivider]="true">
</me-status-bar>
  `}
  dark
  language="html"
/>

### Readonly

В режиме readonly элементы StatusBar не реагируют на клики. В примере показано, как задать свойство `readonly` для элементов, чтобы предотвратить их взаимодействие.

<Canvas name="Readonly" of={statusBarStories.Readonly} />

<Source
  code={`
<me-status-bar
  [leftItems]="[
      { text: 'Воткинская ГЭС', readonly: true },
      { text: 'Раскраска схемы без учета ТП', fill: true, type: 'info', readonly: true },
      { text: 'Режим исследования', fill: true, type: 'success', readonly: true }
  ]"
  [rightItems]="[
    {
      text: 'Отсутствует соединение с источником данных',
      type: 'error',
      icon: 'error',
      fill: true,
      readonly: true,
      onClick: () => { console.log('Этот текст не отобразится в консоли, так как элемент readonly'); }
    }
  ]"
  size="large"
  [showDivider]="true">
</me-status-bar>
  `}
  dark
  language="html"
/>
