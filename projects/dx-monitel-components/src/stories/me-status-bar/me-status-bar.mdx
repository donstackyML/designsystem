# StatusBar

StatusBar - компонент для отображения статусной информации и навигационных элементов.

## Особенности

- Поддержка различных типов статусов (error, warning, success, info)
- Два размера (smsll, large)
- Возможность добавления разделителей
- Поддержка read-only состояния
- Кастомизация через стили DevExtreme

## Использование

```typescript
<me-status-bar
  [leftItems]="[
    {
      text: 'Воткинская ГЭС',
      icon: 'home'
    },
    {
      text: 'Раскраска схемы без учета ТП',
      fill: true,
      type: 'default'
    },
    {
      text: 'Режим исследования'
    }
  ]"
  [rightItems]="[
    {
      icon: 'warning',
      text: 'Отсутствует соединение с источником данных',
      type: 'error'
    }
  ]"
  size="large"
  [showDivider]="true"
></me-status-bar>
```

## API

### StatusBarItem
```typescript
import {StatusType} from "./me-status-bar.component";
interface StatusBarItem {
  icon?: string;           // Иконка
  text: string;            // Текст
  type?: StatusType;       // Тип статуса
  fill?: boolean;          // Использовать заливку фона
  stylingMode?: 'text' | 'contained';  // Режим отображения кнопки (по умолчанию 'text')
}
```

### StatusType
```typescript
type StatusType = 'error' | 'warning' | 'success' | 'info';
```

### Цвета статусов

| Тип статуса | С заливкой (fill: true) | Без заливки |
|-------------|------------------------|-------------|
| error       | Красный фон, белый текст | Красный текст |
| warning     | Оранжевый фон, белый текст | Оранжевый текст |
| success     | Зеленый фон, белый текст | Зеленый текст |
| info        | Синий фон, белый текст | Синий текст |

### Размеры

| Размер | Высота | Размер текста | Размер иконок |
|--------|---------|--------------|---------------|
| small      | 32px    | 14px         | 20px          |
| large      | 48px    | 16px         | 24px          |
