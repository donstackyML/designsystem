# Status Bar

## Компонент meStatusBar

Компонент `meStatusBar` предоставляет информационную панель, отображаемую в нижней части экрана. Он поддерживает отображение статуса организации, основной и дополнительной информации, а также различные типы состояний и индикатор загрузки.

## Базовое использование

Базовый вариант использования компонента с отображением всех основных элементов.

<Canvas of={StatusBarStories.Default} />

<Source
  code={`

  [statusInfo]="{
    organizationName: {
      text: 'Воткинская ГЭС',
      icon: 'home'

    primaryInfo: {
      text: 'Раскраска схемы без узла ТП',
      icon: 'chart'

      text: 'Режим исследования',
      icon: 'clock'

      message: 'Отсутствует соединение с источником данных',

    }
  }"
></me-status-bar>
`}

## Состояние загрузки

Status Bar может отображать состояние загрузки с помощью индикатора.

<Canvas of={StatusBarStories.Loading} />

<Source
  code={`
<me-status-bar
  [statusInfo]="{
    ...baseInfo,
    status: {
      type: 'info',
      message: 'Загрузка данных',
      loading: true
    }
  }"
></me-status-bar>
`}
  dark
  language="html"
/>

## Интерфейсы

### StatusInfo

Основной интерфейс, описывающий структуру данных для Status Bar.

```typescript
interface StatusInfo {
  organizationName: StatusBarItem;
  primaryInfo: StatusBarItem;
  secondaryInfo: StatusBarItem;
  status: {
    type: 'error' | 'success' | 'warning' | 'info';
    message: string;
    icon?: string;
    loading?: boolean;
  };
}
