### Размеры TextArea
Для изменения размеров используйте параметр `size`. Есть три варианта: `small`, `medium`, `large`.

<Source
  code={`<dx-text-area meTextArea size="size"></dx-text-area>`}
  dark
  language="html"
/>

### Положение Label
Для изменения положения Label используйте параметр `labelMode`. Есть три варианта: `top`, `inside`, `hidden`. Для изменения самого Label внутри используйте параметр `label`

<Source
  code={`<dx-text-area meTextArea labelMode="labelMode" label="label"></dx-text-area>`}
  dark
  language="html"
/>

### Состояние ReadOnly и Disabled
Для изменения состояний используйте параметры `readOnly` и `disabled` со значениями `true` и `false`.

<Source
  code={`<dx-text-area meTextArea readOnly="true" disabled="true"></dx-text-area>`}
  dark
  language="html"
/>


#### Контроль высоты и ширины
Для изменения высоты и ширины используйте параметры `height` и `width`.
Для автоматического изменения высоты и ширины используйте параметр `autoResizeEnabled`.	

<Source
  code={`<dx-text-area meTextArea autoResizeEnabled="true"></dx-text-area>`}
  dark
  language="html"
/>

### Валидация поля
Для валидации используйте `<dx-validator>` внутри тэга `dx-text-area`. Для добавления валидации используйте тэг `<dxi-validation-rule>` и параметры `type` и `message`.
Не забудьте импортировать `DxTextAreaModule` и `DxValidatorModule`.
Используйте параметры `validationMessageMode` для изменения режима отображения сообщения об ошибке. Варианты: `auto` и `always`.
Используйте параметр `validationMessagePosition` для изменения положения сообщения об ошибке. Варианты: `top`, `bottom`, `left`, `right`.

<Source
	code={`<dx-text-area meTextArea
  [(validationMessageMode)]="validationMessageMode"
  [(validationMessagePosition)]="validationMessagePosition">
  <dx-validator>
    <dxi-validation-rule 
    type="required"
    message="Required"
    ></dxi-validation-rule>
  </dx-validator>
</dx-text-area>`}
	dark
	language="html"
/>
