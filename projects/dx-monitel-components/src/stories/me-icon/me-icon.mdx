# Icon

## Компонент `me-icon`

Компонент `me-icon` предназначен для отображения иконок в вашем приложении. С его помощью можно легко интегрировать иконки, соответствующие дизайн-системе, и обеспечить единообразное оформление пользовательского интерфейса.
