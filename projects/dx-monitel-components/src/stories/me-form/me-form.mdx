# Form

> ## Директива meForm
>
> Директива `meForm` стилизует `dx-form` компонент в соответствии с дизайн-системой. Работает совместно с директивами `meTextBox`, `meSelectBox`, `meCheckBox` для стилизации полей ввода.

Документация на сайте разработчика DevExtreme:
- [Form API](https://js.devexpress.com/Angular/Documentation/ApiReference/UI_Components/dxForm/)

<Canvas of={formStories.Default} />
<Controls of={formStories.Default} />

## Примеры использования

### Базовая форма

```html
<dx-form
  meForm
  [formData]="formData"
  [size]="'medium'"
  [labelMode]="'floating'"
  [colCount]="2"
>
  <dxi-item dataField="firstName">
    <dxo-label text="First Name"></dxo-label>
    <div *dxTemplate>
      <dx-text-box
        meTextBox
        [(value)]="formData.firstName">
      </dx-text-box>
    </div>
  </dxi-item>
  <dxi-item dataField="email">
    <dxo-label text="Email"></dxo-label>
    <div *dxTemplate>
      <dx-text-box
        meTextBox
        [(value)]="formData.email">
      </dx-text-box>
    </div>
  </dxi-item>
</dx-form>
```

### Группировка полей

<Canvas of={formStories.WithGrouping} />

```html
<dx-form meForm [formData]="formData">
  <dxi-item itemType="group" caption="Personal Info">
    <dxi-item dataField="firstName">
      <dxo-label text="First Name"></dxo-label>
      <div *dxTemplate>
        <dx-text-box meTextBox></dx-text-box>
      </div>
    </dxi-item>
    <dxi-item dataField="lastName">
      <dxo-label text="Last Name"></dxo-label>
      <div *dxTemplate>
        <dx-text-box meTextBox></dx-text-box>
      </div>
    </dxi-item>
  </dxi-item>

  <dxi-item itemType="group" caption="Contact Info">
    <dxi-item dataField="email">...</dxi-item>
    <dxi-item dataField="phone">...</dxi-item>
  </dxi-item>
</dx-form>
```

### Валидация

```html
<dx-form meForm>
  <dxi-item dataField="email">
    <dxi-validation-rule
      type="required"
      message="Email is required">
    </dxi-validation-rule>
    <dxi-validation-rule
      type="email"
      message="Invalid email format">
    </dxi-validation-rule>
    <div *dxTemplate>
      <dx-text-box meTextBox></dx-text-box>
    </div>
  </dxi-item>
</dx-form>
```

### Стили отображения

### Основные параметры:

<section class='table-wrapper'>
| Параметр | Тип | Описание |
|----------|-----|-----------|
| size | 'small' \| 'medium' \| 'large' | Размер компонентов формы |
| labelMode | 'outside' \| 'static' \| 'floating' \| 'hidden' | Режим отображения меток |
| labelLocation | 'left' \| 'top' | Расположение меток |
| colCount | 'auto' \| number | Количество колонок |
| disabled | boolean | Отключение формы |
| readOnly | boolean | Режим только для чтения |
| showColonAfterLabel | boolean | Отображение двоеточия после меток |
</section>
