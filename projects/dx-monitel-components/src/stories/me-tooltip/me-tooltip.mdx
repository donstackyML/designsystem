# Tooltip

## Директива `meTooltip`

Директива `meTooltip` позволяет создавать информативные всплывающие подсказки для элементов пользовательского интерфейса. С её помощью можно:

- **Настроить контент:** Передавать простой текст или HTML-контент, позволяющий форматировать содержимое подсказки (например, выделять текст, добавлять списки, кнопки или изображения).
- **Изменить размеры:** Свойство `tooltipSize` позволяет задать размеры тултипа (`small`, `medium`, `large`), что влияет на отступы и размер шрифтов.
- **Настроить цветовую тему:** Свойство `tooltipColorMode` позволяет выбрать одну из цветовых тем (`default`, `alternate`, `light`, `dark`).
- **Управлять позиционированием:** Свойство `tooltipPosition` задаёт положение тултипа относительно целевого элемента (например, `top`, `bottom`, `left` или `right`).
- **Анимировать появление/исчезновение:** Свойства `tooltipShowAnimation` и `tooltipHideAnimation` позволяют настроить анимационные эффекты для тултипа.

### Позиционирование тултипа

*Пример демонстрирует, как задать позицию тултипа относительно целевого элемента с помощью свойства `tooltipPosition`.*

<Canvas name="Позиционирование тултипа" of={tooltipDirectiveStories.TooltipPositionTop} />
<Source
  code={`<button [meTooltip]="'Это тултип'" [tooltipPosition]="'top'">
  Тултип сверху
</button>`}
  dark
  language="html"
/>

### Анимация тултипа

*Настройка анимации появления и скрытия тултипа производится с помощью свойств `tooltipShowAnimation` и `tooltipHideAnimation`. В примере тултип появляется с эффектом «pop» и исчезает с эффектом «fade».*

<Canvas name="Анимация тултипа" of={tooltipDirectiveStories.WithAnimation} />

<Source
  code={`<button
  [meTooltip]="'Анимированный тултип'"
  [tooltipPosition]="'top'"
  [tooltipShowAnimation]="{ type: 'pop', from: { scale: 0.5, opacity: 0 }, to: { scale: 1, opacity: 1 }, duration: 300 }"
  [tooltipHideAnimation]="{ type: 'fade', from: { opacity: 1 }, to: { opacity: 0 }, duration: 300 }">
  Анимированный тултип
</button>`}
  dark
  language="html"
/>

### Настраиваемость контента тултипа

*Популярность директивы **meTooltip** обусловлена её гибкостью в настройке контента. Вы можете передавать простой текст, использовать HTML-разметку или даже создавать полностью кастомизированные шаблоны для заголовка и основного содержимого тултипа. Такой подход позволяет интегрировать в тултип сложные элементы, такие как заголовки, изображения, списки и кнопки.*

#### Простой текстовый тултип

*Простой вариант, когда в тултип передаётся строка с текстом.*

<Canvas name="Простой текстовый тултип" of={tooltipDirectiveStories.Default} />

<Source
  code={`<button [meTooltip]="'Это базовый тултип'" [tooltipPosition]="'top'">
  Наведи для показа тултипа
</button>`}
  dark
  language="html"
/>

#### Тултип с HTML-контентом

*Тултип может отображать форматированный HTML, что позволяет использовать теги для выделения текста или добавления разметки прямо в содержимое подсказки.*

<Canvas name="Тултип с HTML-контентом" of={tooltipDirectiveStories.WithHTMLContent} />

<Source
  code={`<button [meTooltip]="'<strong>Жирный текст</strong> и <em>курсив</em>'" [tooltipPosition]="'bottom'">
  HTML-тултип
</button>`}
  dark
  language="html"
/>

### Тултип с изображением

*В данном примере тултип отображает сложное содержимое с изображением. Это позволяет встроить в тултип визуальные элементы, такие как баннер или фотография, а также сопроводительный текст. Такой подход полезен, если нужно создать информативную подсказку с графикой.*

<Canvas name="Тултип с изображением" of={tooltipDirectiveStories.WithImageContent} />
<Source
  code={`<button
  [meTooltip]="\`
    <div class='me-tooltip-custom'>
      <div class='me-tooltip-image'>
        <img src='/assets/images/sample.jpg' alt='Sample Image' />
      </div>
      <div class='me-tooltip-content'>
        <h1 class='me-tooltip-title'>Заголовок</h1>
        <p class='me-tooltip-text'>
          Трансформатор – это устройство, способное изменять напряжение переменного тока.
        </p>
      </div>
    </div>
  \`"
  [tooltipPosition]="'right'"
  [tooltipWidth]="390"
  [tooltipClass]="'me-custom-tooltip-wrapper'">
  Тултип с изображением
</button>`}
  dark
  language="html"
/>
