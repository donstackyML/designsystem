# Tooltip

## Директива MeTooltip

Директива `MeTooltip` позволяет создавать информативные всплывающие подсказки для элементов пользовательского интерфейса.

[Ссылка на API компонента DevExtreme](https://js.devexpress.com/Documentation/ApiReference/UI_Components/dxTooltip/)


<Controls of={tooltipStories.Basic} />

## Примеры использования:

### Позиционирование

Тултип можно расположить в различных позициях относительно целевого элемента.

<Story of={tooltipStories.Basic} />

<Source
  code={`<button [meTooltip]="meTooltip" [tooltipPosition]="tooltipPosition">Тултип {{ tooltipPosition }}</button>`}
  dark
  language="html"
/>

### HTML-содержимое

Тултипы могут содержать форматированный HTML-текст.

<Story of={tooltipStories.HTMLContent} />

<Source
  code={`<button [meTooltip]="'<strong>Жирный текст</strong> и <em>курсив</em>'" [tooltipPosition]="tooltipPosition">HTML-тултип</button>`}
  dark
  language="html"
/>

### Анимация

Тултипы могут иметь анимацию появления и исчезновения.

<Story of={tooltipStories.WithAnimation} />

<Source
  code={`
<button
  [meTooltip]="meTooltip"
  [tooltipPosition]="tooltipPosition"
  [tooltipShowAnimation]="tooltipShowAnimation"
  [tooltipHideAnimation]="tooltipHideAnimation">
  Анимированный тултип
</button>
  `}
  dark
  language="html"
/>

<Source
  code={`
<button [meTooltip]="tooltipTemplate"
        [tooltipPosition]="tooltipPosition"
        [tooltipTemplateRef]="tooltipTemplate">
  Тултип с кастомным шаблоном
</button>

  <!-- В компоненте: -->

tooltipTemplate = \`

<div>
  <h4>Заголовок тултипа</h4>
  <p>Это пример тултипа с кастомной разметкой.</p>
  <ul>
    <li>Пункт 1</li>
    <li>Пункт 2</li>
  </ul>
</div>
\`; `} dark language="html" />

### Тултип с изображением

Вы можете создавать сложные тултипы, содержащие изображения, заголовки и форматированный текст.

<Story of={tooltipStories.ImageTooltip} />

<Source
  code={`
<button
  [meTooltip]="tooltipContent"
  [tooltipPosition]="right"
  [tooltipWidth]="300"
  [tooltipClass]="me-custom-tooltip-wrapper">
  Наведите для просмотра тултипа с изображением
</button>

  <!-- HTML контент для тултипа -->
  <div class="me-tooltip-custom">
    <div class="me-tooltip-image">
      <img src="/bg-wave.jpg" alt="Wave" />
    </div>
    <div class="me-tooltip-content">
      <h1 class="me-tooltip-title">Заголовок</h1>
      <p class="me-tooltip-text">
        Трансформатор - это устройство, способное изменять
        напряжение переменного тока
      </p>
    </div>
  </div>

  <!-- Стили для тултипа -->
  <style>
  .me-tooltip-custom {
    overflow: hidden;
    background: #18181A;
    color: #fff;
  }

  .me-tooltip-image {
    width: 100%;
    height: 140px;
    overflow: hidden;
  }

  .me-tooltip-title {
    font-size: 20px;
    font-weight: 600;
    line-height: 24px;
  }

  .me-tooltip-text {
    font-size: 14px;
    font-weight: 400;
    line-height: 20px;
  }
  </style>
`}
  dark
  language="html"
/>
