# Card

Компонент `Card` представляет собой контейнер для отображения контента в виде карточки с возможностью настройки заголовка, содержимого и подвала.

## Базовое использование

<Story of={Stories.ComplexCard} />

В этом примере показана карточка со всеми основными элементами:
- Заголовок с кнопками и чипами
- Основной контент
- Подвал с кнопками действий

<Source of={Stories.ComplexCard} />

## Карточка с прокруткой

<Story of={Stories.ScrollableContent} />

Карточка с фиксированной высотой контента и прокруткой. Когда содержимое превышает указанную высоту, появляется полоса прокрутки.

<Source
  code={`
<me-card
  [size]="'medium'"
  [showHeader]="true"
  [showFooter]="true"
  [contentHeight]="'200px'"
>
  <!-- Header -->
  <ng-container card-header-left>
    <span>Карточка с прокруткой</span>
  </ng-container>

    <!-- Scrollable Content -->
    <div>
      <p>Содержимое с прокруткой...</p>
    </div>

    <!-- Footer -->
    <ng-container card-footer>
      <dx-button
        meButton
        text="Cancel"
        [stylingMode]="'text'"
      ></dx-button>
      <dx-button
        meButton
        text="Save"
        [stylingMode]="'contained'"
      ></dx-button>
    </ng-container>
  </me-card>
`} />

## Карточка без ограничения высоты

<Story of={Stories.UnlimitedContent} />

Карточка без ограничения высоты контента. Размер карточки адаптируется под содержимое.

<Source
  code={`
<me-card
  [size]="'medium'"
  [showHeader]="true"
  [showFooter]="true"
>
  <!-- Header -->
  <ng-container card-header-left>
    <span>Карточка без ограничения высоты</span>
  </ng-container>

    <!-- Content -->
    <div>
      <h3>Раздел</h3>
      <p>Содержимое раздела...</p>
    </div>

    <!-- Footer -->
    <ng-container card-footer>
      <dx-button
        meButton
        text="Cancel"
        [stylingMode]="'text'"
      ></dx-button>
      <dx-button
        meButton
        text="Save"
        [stylingMode]="'contained'"
      ></dx-button>
    </ng-container>
  </me-card>
`} />

## Описание входных параметров

- `size`: Размер карточки ('small' | 'medium' | 'large')
- `showHeader`: Показывать ли заголовок карточки
- `showFooter`: Показывать ли подвал карточки
- `contentHeight`: Максимальная высота контента (например, '200px')

## Слоты для контента

Компонент предоставляет несколько слотов для размещения контента:

1. `card-header-left` - левая часть заголовка
2. `card-header-right` - правая часть заголовка
3. Основной контент (без специального селектора)
4. `card-footer` - подвал карточки

Пример использования слотов:

<Source
  code={`
<me-card [size]="'medium'">
  <ng-container card-header-left>
    <!-- Содержимое левой части заголовка -->
  </ng-container>

    <ng-container card-header-right>
      <!-- Содержимое правой части заголовка -->
    </ng-container>

    <!-- Основной контент -->
    <div>
      <p>Основное содержимое карточки</p>
    </div>

    <ng-container card-footer>
      <!-- Содержимое подвала -->
    </ng-container>
  </me-card>
`} />
