# FileUploader

Директива `meFileUploader` предоставляет стилизацию для компонента DxFileUploader в соответствии с дизайн-системой.

## Основные возможности

- Поддержка drag & drop
- Валидация типов файлов
- Отображение прогресса загрузки
- Множественная загрузка
- Отложенная загрузка с кнопками
- Загрузка файлов по частям
- Кастомная зона для drag & drop

## Кастомная дроп-зона

В дополнение к стандартному поведению компонента FileUploader (используемого в составе директивы `MeFileUploader`), вы можете создать кастомную дроп-зону для более гибкой настройки интерфейса загрузки файлов. Это особенно полезно, если вам нужно отобразить дополнительную информацию, превью изображений, индикатор прогресса или собственный текст.

### Пример использования кастомной дроп-зоны

В примере ниже мы создаем область для перетаскивания файла, добавляем прогресс-бар для отображения хода загрузки, а также реализуем логику подсветки зоны при переносе файла и предварительный просмотр загруженного изображения.

```html
<div class="widget-container flex-box">
  <span>Profile Picture</span>
  <div
    id="dropzone-external"
    class="flex-box"
    [ngClass]="isDropZoneActive ? 'dropzone-active' : null"
  >
    <img id="dropzone-image" [src]="imageSource" *ngIf="imageSource" alt="" />
    <div id="dropzone-text" class="flex-box" *ngIf="textVisible">
      <span>Drag & Drop the desired file</span>
      <span>…or click to browse for a file instead.</span>
    </div>
    <dx-progress-bar
      #uploadProgress
      [min]="0"
      [max]="100"
      width="30%"
      [showStatus]="false"
      [visible]="progressVisible"
      [value]="progressValue"
    ></dx-progress-bar>
  </div>
  <dx-file-uploader
    #fileUploader
    dialogTrigger="#dropzone-external"
    dropZone="#dropzone-external"
    [multiple]="false"
    [allowedFileExtensions]="allowedFileExtensions"
    uploadMode="instantly"
    [visible]="false"
    (onDropZoneEnter)="onDropZoneEnter($event)"
    (onDropZoneLeave)="onDropZoneLeave($event)"
    (onUploaded)="onUploaded($event)"
    (onProgress)="onProgress($event)"
    (onUploadStarted)="onUploadStarted()"
  ></dx-file-uploader>
</div>
```

## События

FileUploader поддерживает следующие основные события:

- `onUploadStarted` - начало загрузки файла
- `onUploaded` - файл успешно загружен
- `onProgress` - прогресс загрузки файла
- `onUploadError` - ошибка при загрузке
- `onValueChanged` - изменение выбранных файлов
- `onDropZoneEnter` - файл перетащен в зону загрузки
- `onDropZoneLeave` - файл убран из зоны загрузки

Пример обработки событий:

<Source
  code={`
<dx-file-uploader
  meFileUploader
  (onUploadStarted)="onUploadStarted($event)"
  (onUploaded)="onUploaded($event)"
  (onProgress)="onProgress($event)"
  (onUploadError)="onUploadError($event)"
>
</dx-file-uploader>

  // В компоненте
  onUploadStarted(e) {
    console.log('Upload started:', e);
  }

  onUploaded(e) {
    console.log('File uploaded:', e);
  }

  onProgress(e) {
    const progress = e.bytesLoaded / e.bytesTotal * 100;
    console.log('Upload progress:', progress);
  }

  onUploadError(e) {
    console.error('Upload error:', e);
  }
`}
  dark
  language="typescript"
/>
