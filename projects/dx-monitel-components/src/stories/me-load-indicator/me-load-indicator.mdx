# LoadIndicator

## Директива `meLoadIndicator`

Директива `meLoadIndicator` позволяет создавать индикаторы загрузки с различными параметрами, включая размер, цвет и иконка.

## Изменение размера индикатора

Для изменения размера индикатора используйте параметр `size`. Возможные значения: `small`, `medium` и `large`.

<Source
  code={`<dx-load-indicator meLoadIndicator size="size"></dx-load-indicator>`}
  dark
  language="html"
/>

## Изменение цвета индикатора

Для изменения цвета индикатора используйте параметр `color`. Возможные значения: `normal`, `default`, `accent`

<Source
  code={`<dx-load-indicator meLoadIndicator color="color"></dx-load-indicator>`}
  dark
  language="html"
/>

## Изменение стиля индикатора

Для изменения стиля индикатора используйте параметр `stylingMode`. Возможные значения: `line`, `circle`.

<Source
  code={`<dx-load-indicator meLoadIndicator stylingMode="stylingMode"></dx-load-indicator>`}
  dark
  language="html"
/>

## Использование пользовательского индикатора

Для использования пользовательского индикатора используйте параметр `indicatorSrc`.

<Source
  code={`<dx-load-indicator meLoadIndicator indicatorSrc="indicatorSrc"></dx-load-indicator>`}
  dark
  language="html"
/>
