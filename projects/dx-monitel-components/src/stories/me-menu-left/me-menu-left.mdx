# Menu Left

## Компонент `me-menu-left`

Компонент `me-menu-left` — это универсальный контейнер для отображения информации в виде карточки. Компонент использует архитектуру слотов.

## API

### Слоты (ng-content)

| Название слота    | Описание                                                                            |
| ----------------- | ----------------------------------------------------------------------------------- |
| `meMenuLeftHeader` | Контейнер для верхней части меню, например, заголовка или иконок.                   |
| `meMenuLeftSearch` | Слот для области поиска. Размещается между заголовком и основным списком элементов. |
