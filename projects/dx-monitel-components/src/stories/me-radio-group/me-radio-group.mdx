# RadioGroup

## Директива meRadioGroup

Применение директивы <code>meRadioGroup</code> к элементу <code>dx-radio-group</code> предоставляет следующие возможности:

- Установка размера через свойство <code>size</code> (small, medium, large)
- Выбор расположения элементов через свойство <code>layout</code> (vertical, horizontal)
- Подключение данных через свойство <code>dataSource</code>
- Кастомизация отображения элементов через <code>itemTemplate</code>

[Ссылка на API компонента DevExtreme](https://js.devexpress.com/Angular/Documentation/ApiReference/UI_Components/dxRadioGroup/)
