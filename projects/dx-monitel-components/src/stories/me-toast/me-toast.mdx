# Toast

## Описание

Компонент `Toast` используется для отображения уведомлений различных типов: информационных сообщений, предупреждений, ошибок и уведомлений об успешных операциях.

## Размеры и типы

Toast поддерживает два размера:
- Маленький (small) - для простых уведомлений
- Большой (large) - для уведомлений с дополнительными действиями

И четыре типа:
- Информационный (info)
- Предупреждение (warning)
- Ошибка (error)
- Успех (success)

    ## API

    ### Свойства компонента

    | Свойство | Тип | Описание |
    |----------|-----|----------|
    | type | 'info' \| 'warning' \| 'error' \| 'success' | Тип уведомления |
    | visible | boolean | Флаг видимости уведомления |
    | displayTime | number | Время отображения в миллисекундах |

    ### CSS классы

    | Класс | Описание |
    |-------|----------|
    | me-toast-content | Базовый класс для контейнера уведомления |
    | me-toast-small | Класс для маленького уведомления |
    | me-toast-large | Класс для большого уведомления |
    | me-toast-header | Класс для заголовка уведомления |
    | me-toast-content1 | Класс для отступа контента в больших уведомлениях |
    | me-toast-content2 | Класс для отступа контента в маленьких уведомлениях |
    | me-toast-actions | Класс для контейнера с кнопками действий |
    | me-toast-close-button | Класс для кнопки закрытия |
