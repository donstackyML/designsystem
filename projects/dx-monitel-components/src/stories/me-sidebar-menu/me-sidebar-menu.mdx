# SidebarMenu

SidebarMenu - компонент для создания бокового навигационного меню с возможностью сворачивания.

## Особенности

- Древовидная структура на основе DevExtreme TreeView
- Поддержка сворачивания/разворачивания
- Поиск по пунктам меню
- Поддержка иконок и бейджей
- Кастомные шаблоны элементов
- Адаптивный дизайн

### Интерфейс MeSidebarMenuItem

<Source
  language="typescript"
  code={`
interface MeSidebarMenuItem {
  text: string;           // Текст пункта меню
  icon?: string;          // Путь к SVG иконке
  expanded?: boolean;     // Начальное состояние раскрытия
  items?: MeSidebarMenuItem[]; // Дочерние элементы
  badge?: number;         // Счетчик/бейдж

`} />

### Размеры

| Состояние  | Ширина | Примечание                  |
|------------|--------|----------------------------|
| Развернуто | 280px  | Показываются текст и иконки |
| Свернуто   | 64px   | Показываются только иконки  |

### События

| Событие         | Тип                  | Описание                                |
|-----------------|----------------------|-----------------------------------------|
| itemSelected    | `EventEmitter`       | Срабатывает при выборе пункта меню      |
| collapsedChange | `EventEmitter`       | Срабатывает при сворачивании/разворачивании |

### Лучшие практики

1. **Иконки**
   - Используйте SVG для лучшей масштабируемости
   - Размер иконок: 24x24px
   - Поддерживайте единый стиль иконок

2. **Структура меню**
   - Ограничивайте вложенность 2-3 уровнями
   - Группируйте связанные пункты
   - Используйте бейджи умеренно

3. **Производительность**
   - Включайте поиск только при необходимости
   - Для больших меню используйте виртуальную прокрутку

4. **Доступность**
   - Используйте ARIA-атрибуты
   - Обеспечьте навигацию с клавиатуры
   - Поддерживайте контрастные цвета

### Известные ограничения

1. В свернутом состоянии:
   - Не отображаются бейджи
   - Поиск недоступен
   - Всплывающие подсказки для иконок

2. Технические:
   - Максимальная ширина в развернутом состоянии: 280px
   - Минимальная ширина в свернутом состоянии: 64px
   - Максимальное количество уровней вложенности: 3
