# DropDownButton

## Директива meDropDownButton

Применение директивы <code>meDropDownButton</code> к элементу <code>dx-drop-down-button</code> приводит
его размеры к значению <code>size = medium (32)</code> из дизайн-системы и предоставляет доступ к другим свойствам.

[API](https://js.devexpress.com/Angular/Documentation/ApiReference/UI_Components/dxDropDownButton/)

[Демо](https://js.devexpress.com/Angular/Demos/WidgetsGallery/Demo/DropDownButton/Overview/Light/)

### Стилизация кнопки

- Для настройки стиля кнопки используйте параметр <code>stylingMode</code>: `contained`, `outlined`, `text`.
- Для настройки типа кнопки используйте параметр <code>type</code>: `default`, `normal`, `success`, `danger`.
- Для настройки размера кнопки используйте параметр <code>size</code>: `small`, `medium`, `large`.
- Для разделения кнопки используйте параметр <code>splitButton</code>: `true`, `false`.


<Source code={
`<dx-drop-down-button
  meDropDownButton
  [splitButton]="true"
	[stylingMode]="'contained'"
	[type]="'success'"
	[size]="'small'">
>
</dx-drop-down-button>
`} dark />

### Кнопка с иконкой

Используйте параметр `icon` для установки иконки. Это свойство принимает одно из следующих значений:

- URL-адрес значка
- Название значка, если значок находится в библиотеке значков DevExtreme
- CSS-класс значка, если значок взят из внешней библиотеки значков (см. Внешние библиотеки значков)
- Значок в формате Base64
- Значок в формате SVG. Убедитесь, что источник надежный.

<Source code={
`<dx-drop-down-button
  meDropDownButton
  [icon]="'add'">
</dx-drop-down-button>
`} dark />
