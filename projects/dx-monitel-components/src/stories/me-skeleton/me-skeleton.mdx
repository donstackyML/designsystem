### С аватаром

<Canvas of={SkeletonStories.WithAvatar} />

Свойство `avatar` может принимать объект из двух свойств

| Свойство | Тип                                               | Описание                                                                                                      |
|----------|---------------------------------------------------|---------------------------------------------------------------------------------------------------------------|
| size     | `number` \| `'large'` \| `'small'` \| `'default'` | Определяет размер аватара. Если передано число, устанавливается размер в пикселях равный переданному значению |
| shape    | `'circle'` \| `'square'`                          | Определяет форму аватара                                                                                      |

<Source
  code={`<me-skeleton [avatar]="{ size: 'large', shape: 'circle' }"></me-skeleton>`}
  dark
  language="html"
/>

### Настраиваемый заголовок и параграфы

Свойство `title` может принимать либо значение `true` для отображения заголовка с шириной по умолчанию, либо принимать объект с настройками

| Свойство | Тип                  | Описание                                                                                                                                                                  |
|----------|----------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| width    | `number` \| `string` | Определяет ширину заголовка. Если передано число, устанавливается размер в пикселях равный переданному значению. Если передана строка, устанавливается переданное значение |

Свойство `paragraph` может принимать либо значение `true` для отображения текста с шириной и количеством строк по умолчанию, либо принимать объект с настройками

| Свойство | Тип                                                   | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
|----------|-------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| rows     | `number`                                              | Определяет количество строк для отображения                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| width    | `{ width: number \| string \| (number \| string)[] }` | Определяет ширину строк. Имеет несколько режимов поведения в зависимости от переданного значения:<br/>-`number` - если передано число, последней строке устанавливается размер в пикселях равный переданному значению, а остальным строкам 100%<br/> - `string` - если передан типа строка, последней строке в тексте устанавливается переданное значение, а остальным строкам 100%<br/> - `(number \| string)[]` - если передан массив, то его длина имеет большие приоритет, чем значение в свойстве `rows`. А ширина каждой строки определяется соответствующим элементом в масссиве<br/><br/>Если не переданы настройки ширины в `width`, то всем строкам устанавливается ширина 100% |

<Canvas of={SkeletonStories.CustomTitleAndParagraph} />
<Source
  code={`
<me-skeleton
  [title]="{ width: '40%' }"
  [paragraph]="{ width: ['100%', '90%', '80%', '60%'] }">
</me-skeleton>
`}
  dark
  language="html"
/>
