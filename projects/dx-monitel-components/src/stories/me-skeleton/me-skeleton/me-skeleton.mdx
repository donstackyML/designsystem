# Skeleton

## Компонент `me-skeleton`

Компонент `me-skeleton` предоставляет визуальную заглушку во время загрузки контента или для отображения отсутствующего контента.

### С аватаром

<Canvas of={skeletonStories.WithAvatar} />

Свойство `avatar` может принимать объект с параметрами для настройки аватара. Возможны следующие свойства:

| Свойство | Тип                                               | Описание                                                                                                      |
|----------|---------------------------------------------------|---------------------------------------------------------------------------------------------------------------|
| size     | `number` \| `'large'` \| `'small'` \| `'default'`  | Предопределённый размер аватара. Если передано число, используется размер в пикселях.                           |
| width    | `number` \| `string`                              | Задает произвольную ширину аватара. Приоритет выше, чем значение в `size`.                                      |
| height   | `number` \| `string`                              | Задает произвольную высоту аватара. Приоритет выше, чем значение в `size`.                                      |
| shape    | `'circle'` \| `'square'` \| `'rectangle'`         | Определяет форму аватара.                                                                                       |

<Source
  code={`<me-skeleton [avatar]="{ size: 'large', shape: 'circle' }"></me-skeleton>`}
  dark
  language="html"
/>

### Настраиваемый заголовок и параграфы

Свойство `title` может принимать либо значение `true` для отображения заголовка с настройками по умолчанию, либо объект с параметрами.

| Свойство | Тип                  | Описание                                                                                                                                                                  |
|----------|----------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| width    | `number` \| `string` | Определяет ширину заголовка. Если передано число, используется значение в пикселях; если строка – значение применяется напрямую.                                             |

Свойство `paragraph` может принимать либо значение `true` для отображения текста по умолчанию, либо объект с параметрами:

| Свойство | Тип                                                   | Описание                                                                                                                                                                                                                                                                                                                                                                                                |
|----------|-------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| rows     | `number`                                              | Определяет количество строк.                                                                                                                                                                                                                                                                                                                                                                            |
| width    | `number` \| `string` \| `(number \| string)[]`         | Определяет ширину строк. Если передан массив, его длина имеет приоритет над значением `rows`. При передаче числа или строки, последней строке применяется указанное значение, а для остальных используется 100%.                                                                                                                                                                                     |
| height   | `number` \| `string`                                  | Определяет высоту строк. Если задано, применяется ко всем строкам.                                                                                                                                                                                                                                                                                                                                      |
| gap      | `string`                                              | Межстрочный интервал, который устанавливается как CSS-переменная и переопределяет отступы, заданные в классах.                                                                                                                                                                                                                                                                                        |

<Canvas of={skeletonStories.CustomTitleAndParagraph} />

<Source
  code={`
<me-skeleton
  [title]="{ width: '40%' }"
  [paragraph]="{ rows: 4, width: ['100%', '90%', '80%', '60%'] }">
</me-skeleton>
`}
  dark
  language="html"
/>

### Настройка межстрочного интервала

<Canvas of={skeletonStories.ParagraphAndContentSpacing} />

<Source
  code={`
<me-skeleton
  [paragraph]="{ rows: 4, width: ['100%', '90%', '80%', '70%'], gap: '20px', height: '12px' }"
  [title]="null"
  [avatar]="null">
</me-skeleton>
`}
  dark
  language="html"
/>

В этом примере свойство `gap` в объекте `paragraph` используется для задания межстрочного интервала, переопределяя отступы, заданные в классах.

### Кастомный контент

<Canvas of={skeletonStories.Custom} />

<Source
  code={`
<me-skeleton [animated]="true" [title]="{ width: '50%' }" [shape]="'rounded'">
  <div customParagraph class="custom-paragraph">
    <me-skeleton-item [animated]="animated" width="100%"></me-skeleton-item>
    <me-skeleton-item [animated]="animated" width="80%"></me-skeleton-item>
    <me-skeleton-item [animated]="animated" width="20%"></me-skeleton-item>
  </div>
</me-skeleton>
`}
  dark
  language="html"
/>

В этом примере используется контент-проекция через слот `customParagraph` и привязка к элементу с идентификатором `#customParagraph` для задания кастомного отображения параграфа.
