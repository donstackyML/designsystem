# ProgressBar

## Директива meProgressBar

Директива `meProgressBar` расширяет настройки и изменяет внешний вид стандартного компонента `ProgressBar DevExtreme`, добавляя дополнительные размеры.

## Размеры прогрессбара

Для изменения размера прогрессбара используйте `size`. Имеются два варианта размера: `small` и `medium`.

<Source
  code={`<dx-progress-bar meProgressBar [size]="size"></dx-progress-bar>`}
  dark
  language="html"
/>

## Статус прогресса

Для отображения статуса прогресса используйте свойство `showStatus="true"`.

<Source
  code={`<dx-progress-bar meProgressBar [showStatus]="true"></dx-progress-bar>`}
  dark
  language="html"
/>

## Обложка прогрессбара

Компонент DevExtreme ProgressBar не поддерживает обложку, поэтому обложка создается и стилизуется отдельно как в примере.

## Small
<Source
			code={`
  <div class="form">
    <div class="me-text-body2"> Time left 00:00:10 </div>
      <dx-progress-bar
        meProgressBar
        #progressBar
        id="progress-bar-status"
        [(value)]="value"
        [(size)]="size"
        [(height)]="height"
        [(width)]="width"
        [(showStatus)]="showStatus"
      >
      </dx-progress-bar>
    </div>
`}
  dark
  language="html"
/>
<Source
			code={`
  .form {
      height: 100px;
      text-align: center;
      align-content: center;
    }
    .me-text-body2 {
      text-align: center;
    }
    #progress-bar-status {
      display: inline-block;
      padding-top: 2px;
    }
`}
  dark
  language="css"
/>
