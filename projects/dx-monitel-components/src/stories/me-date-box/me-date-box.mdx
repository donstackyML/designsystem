# DateBox

## Директива meDateBox

Применение директивы meDateBox к элементу <code>dx-date-box</code> приводит его размеры к значению <code>size=medium</code> из дизайн-системы, а также приводит отступы в соответствие
с дизайн-системой, добавляет свойство <code>size</code>.

Документация на сайте разработчика Devextreme:

[API](https://js.devexpress.com/Angular/Documentation/ApiReference/UI_Components/dxDateBox/)

### Размеры DateBox
Для изменения размеров используйте параметр `size`. Есть три варианта: `small`, `medium`, `large`.

<Source
	code={`<dx-date-box meDateBox size="size"></dx-date-box>`}
	language="html"
	dark
/>

### Положение Label
Для изменения положения Label используйте параметр `labelMode`. Есть три варианта: `static`, `floating`, `hidden`, `outside`. Для изменения самого Label внутри используйте параметр `label`

<Source
  code={`<dx-date-box meDateBox labelMode="labelMode" label="label"></dx-date-box>`}
  dark
  language="html"
/>

Для того, чтобы установить label слева от элемента, используйте тэг обертку `label` с директивой `meLabel` и параметром `labelDirection="row"`, установив параметр `labelMode="hidden"` в <code>meDateBox</code>.

<Source
			code={`
<label meLabel 
labelDirection="row">
  <dx-date-box meDateBox labelMode="hidden"></dx-date-box>
</label>`}
	dark
	language="html"
/>
<Canvas of={DateBoxStories.WithLabelRow} />

### Валидация поля
Для валидации используйте `<dx-validator>` внутри тэга `dx-date-box`. Для добавления валидации используйте тэг `<dxi-validation-rule>` и параметры `type` и `message`.
Не забудьте импортировать `DxTextAreaModule` и `DxValidatorModule`.
Используйте параметры `validationMessageMode` для изменения режима отображения сообщения об ошибке. Варианты: `auto` и `always`.
Используйте параметр `validationMessagePosition` для изменения положения сообщения об ошибке. Варианты: `top`, `bottom`, `left`, `right`.

<Source
	code={`<dx-date-box meTextArea
[(validationMessageMode)]="validationMessageMode"
[(validationMessagePosition)]="validationMessagePosition">
  <dx-validator>
    <dxi-validation-rule 
    type="required"
    message="Required"
    ></dxi-validation-rule>
  </dx-validator>
</dx-date-box>`}
	dark
	language="html"
/>

## Тип DateBox

Для настроек типа используйте параметр `type`. Есть три варианта: `date`, `datetime`, `time`. По умолчанию тип DateBox - `date`.
Так же можно включить отображение аналоговых часов, установив `showAnalogClock=true`.

<Source
	code={`<dx-date-box meDateBox 
  type="type"
  showAnalogClock="true"
></dx-date-box>`}
	language="html"
	dark
/>


## Ввод даты
Установив параметр `acceptCustomValue=true` можно вводить дату вручную.

<Source
	code={`<dx-date-box meDateBox 
  acceptCustomValue="true"
></dx-date-box>`}
	language="html"
	dark
/>

## Формат даты и времени
`dateSerializationFormat` позволяет задать формат даты и времени, которые будут отображаться в компоненте. Примеры вариантов есть выше в контроллерах и на сайте DevExtreme.

<Source
	code={`<dx-date-box meDateBox 
dateSerializationFormat="dateSerializationFormat"
></dx-date-box>`}
	language="html"
	dark
/>

## Настройка дат для выбора

`disabledDates` позволяет задать даты, которые пользователи не могут выбрать.
`calendarOptions` позволяет задать настройки календаря. Необходимо передать объект с настройками. Возможности календаря приведены в документации к соответствующему компоненту DevExtreme.

<Source
	code={`<dx-date-box meDateBox 
disabledDates="2024-04-22"
calendarOptions="{
  showWeekNumbers: true,
  max: '2024-12-31',
  min: '2023-12-31',}"
></dx-date-box>`}
	language="html"
	dark
/>
