# DateBox

## Директива `meDateBox`

Применение директивы `meDateBox` к элементу `<dx-date-box>` приводит его к оформлению, соответствующему дизайн-системе: задаются стандартные отступы, размеры (по умолчанию — `size="medium"`) и стилизация лейбла. Дополнительно доступны параметры для управления поведением компонента.

### Изменение положения лейбла с помощью директивы meLabel

Для вывода лейбла вне текстового поля можно использовать директиву `meLabel`. Это позволяет разместить метку отдельно от самого поля, задавая её положение с помощью свойства `labelDirection`.

#### Положение лейбла сверху

Чтобы лейбл располагался над текстовым полем, оберните компонент в контейнер с директивой `meLabel` и установите `labelDirection="column"`. Это позволяет создать вертикальное расположение, где метка находится сверху, а само поле — под ней.

<Canvas name="Лейбл сверху" of={dateBoxStories.WithLabelColumn} />

<Source
  code={`
<div meLabel labelDirection="column">
  <span>Label</span>
  <dx-date-box meDateBox labelMode="hidden"></dx-date-box>
</div>
`}
  language="html"
  dark
/>

#### Положение лейбла слева

Чтобы разместить лейбл слева от текстового поля, используйте `labelDirection="row"`. Для корректного выравнивания задайте фиксированную ширину контейнера, например, через атрибут `width`.

<Canvas name="Лейбл слева" of={dateBoxStories.WithLabelRow} />

<Source
  code={`
<div meLabel labelDirection="row" class="dx-widget">
  <span>Label</span>
  <dx-date-box meDateBox labelMode="hidden"></dx-date-box>
</div>
`}
  language="html"
  dark
/>

### Валидация поля

Для валидации значения внутри DateBox используйте компонент `<dx-validator>`, вложенный в `<dx-date-box>`. Добавьте правило валидации с помощью `<dxi-validation-rule>` и настройте параметры отображения сообщений с помощью `validationMessageMode` и `validationMessagePosition`.

<Source
  code={`
<dx-date-box
  meDateBox
  [(validationMessagePosition)]="validationMessagePosition"
  [(validationMessagePosition)]="validationMessagePosition"
  >
  <dx-validator>
    <dxi-validation-rule
      type="required"
      message="Required"
    ></dxi-validation-rule>
  </dx-validator>
</dx-date-box>
`}
  language="html"
  dark
/>

### Тип DateBox

Параметр `type` определяет тип значения, отображаемого в DateBox. Доступны три варианта:
- `date` — выбор даты (по умолчанию),
- `datetime` — выбор даты и времени,
- `time` — выбор времени.

<Canvas of={dateBoxStories.PickerTypeCalendar} />
<Source
  code={`
<dx-date-box meDateBox
  type="date"
  pickerType="calendar">
</dx-date-box>
`}
  language="html"
  dark
/>

Для отображения аналоговых часов при выборе даты установите параметр `showAnalogClock="true"` с типом `type="datetime"`.

<Canvas of={dateBoxStories.DateAndTime} />
<Source
  code={`
<dx-date-box meDateBox
  type="datetime"
  showAnalogClock="true">
</dx-date-box>
`}
  language="html"
  dark
/>

### Формат даты и времени

Параметр `dateSerializationFormat` задаёт формат, по которому будет сериализоваться и отображаться дата в компоненте.

<Source
  code={`
<dx-date-box meDateBox
  dateSerializationFormat="yyyy-MM-dd">
</dx-date-box>
`}
  language="html"
  dark
/>

### Настройка дат для выбора

С помощью параметра `disabledDates` можно задать даты, которые невозможно выбрать. Дополнительно, через параметр `calendarOptions` можно передать объект с настройками календаря (например, установить минимальную и максимальную дату, включить показ номеров недель и пр.).

<Source
  code={`
<dx-date-box meDateBox
  disabledDates="2024-04-22"
  calendarOptions="{
    showWeekNumbers: true,
    min: '2023-12-31',
    max: '2024-12-31'
  }">
</dx-date-box>
`}
  language="html"
  dark
/>
