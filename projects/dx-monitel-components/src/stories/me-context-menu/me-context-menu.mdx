# ContextMenu

> ## Директива meContextMenu
>
> Применение директивы `meContextMenu` к элементу `dx-context-menu` приводит его внешний вид в соответствие с дизайн-системой.

### Базовое использование

<Canvas of={contextmenuStories.Default} />

```html
<dx-button meButton text="Right click" id="contextButton"></dx-button>
<dx-context-menu
  meContextMenu
  [dataSource]="dataSource"
  target="#contextButton">
</dx-context-menu>
```

### Выбранные элементы

<Canvas of={contextmenuStories.SelectedItems} />

> Состояние `selected` устанавливается в dataSource:

```typescript
dataSource: [
  {
    text: 'Share',
    icon: 'globe',
    items: [
      { text: 'Facebook', selected: true },
      { text: 'Twitter' }
    ]
  },
  { text: 'Add to Favorite', selected: true }
]
```

### Заголовки групп

> Для добавления заголовка группы используйте следующие свойства:

```typescript
{
  text: 'Заголовок группы',
  icon: iconService.getIcon({ icon: 'public', size: '24' }),
  disabled: true, // отключает hover и active состояния
  beginGroup: true // добавляет разделитель
}
```

### Основные параметры:

- `dataSource` - данные для отображения
- `target` - элемент, на котором вызывается контекстное меню
- `selectionMode` - режим выделения (`single`, `multiple`, `all`, `none`)
- `items` - вложенные пункты меню
- `disabled` - отключение пункта меню
- `beginGroup` - начало новой группы с разделителем
