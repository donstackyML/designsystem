# ContextMenu

> ## Директива meContextMenu
>
> Применение директивы `meContextMenu` к элементу `dx-context-menu` приводит его внешний вид в соответствие с дизайн-системой.

Документация на сайте разработчика DevExtreme:
- [API](https://js.devexpress.com/Angular/Documentation/ApiReference/UI_Components/dxContextMenu/)
- [Демо](https://js.devexpress.com/Angular/Demos/WidgetsGallery/Demo/ContextMenu/Basics/MaterialBlueLight/)
