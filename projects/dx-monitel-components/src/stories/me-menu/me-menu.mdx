# Menu

> ## Директива meMenu
>
> Применение директивы `meMenu` к элементу `dx-menu` стилизует компонент в соответствии с дизайн-системой. По умолчанию устанавливает `size = large (L)`.

<Canvas of={menuStories.Default} />
<Controls of={menuStories.Default} />

## Примеры использования

### Базовое меню

```html
<dx-menu
  meMenu
  [dataSource]="menuItems"
  [orientation]="'horizontal'"
  [size]="'large'"
  showFirstSubmenuMode="onHover"
  showSubmenuMode="onHover"
>
</dx-menu>
```

### Данные для меню

```typescript
const menuItems = [
  {
    icon: 'folder',
    text: 'Electronics',
    items: [
      {
        icon: 'folder',
        text: 'Computers',
        items: [
          { text: 'Desktops' },
          { text: 'Laptops' }
        ]
      },
      {
        icon: 'folder',
        text: 'Phones',
        items: [
          { text: 'Smartphones' },
          { text: 'Accessories' }
        ]
      }
    ]
  },
  {
    icon: 'folder',
    text: 'Entertainment',
    items: [/*...*/]
  }
];
```

### Вертикальное меню

```html
<dx-menu
  meMenu
  [dataSource]="menuItems"
  [orientation]="'vertical'"
  [size]="'large'"
>
</dx-menu>
```

### С выделением элементов

```html
<dx-menu
  meMenu
  [dataSource]="menuItems"
  [selectByClick]="true"
  [selectionMode]="'single'"
>
</dx-menu>
```

## API Reference

### Основные параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|-----------|
| size | 'small' \| 'large' | 'large' | Размер меню и элементов |
| orientation | 'vertical' \| 'horizontal' | 'horizontal' | Ориентация меню |
| dataSource | array | [] | Данные для пунктов меню |
| selectByClick | boolean | false | Выбор элементов по клику |
| selectionMode | 'single' \| 'multiple' \| 'none' | 'none' | Режим выделения |
| showFirstSubmenuMode | string | 'onHover' | Режим показа первого подменю |
| showSubmenuMode | string | 'onHover' | Режим показа остальных подменю |

### Структура dataSource

| Свойство | Тип | Описание |
|----------|-----|-----------|
| text | string | Текст пункта меню |
| icon | string | Иконка |
| items | array | Дочерние пункты меню |
| disabled | boolean | Отключение пункта |
| visible | boolean | Видимость пункта |
| beginGroup | boolean | Начало новой группы |

### События

- `onItemClick` - клик по пункту меню
- `onSelectionChanged` - изменение выделения
- `onSubmenuShowing` - показ подменю
- `onSubmenuShown` - подменю показано
- `onSubmenuHiding` - скрытие подменю
- `onSubmenuHidden` - подменю скрыто
