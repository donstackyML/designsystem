# Badge

Badge (бейдж) используется для отображения числовых индикаторов, таких как количество уведомлений, сообщений или других метрик.

## Основные примеры

<Story of={Stories.BasicExamples} />

Базовый бейдж доступен в пяти цветовых вариантах: default, secondary, success, attention и error.

## Размеры

<Story of={Stories.Sizes} />

Бейдж имеет два размера:
- Small (20px)
- Large (24px)

## Длинные числа

<Story of={Stories.LongNumbers} />

При отображении чисел больше 99 бейдж автоматически расширяется, сохраняя читаемость значения.

## Все варианты

<Story of={Stories.AllVariants} />

Демонстрация всех возможных комбинаций размеров и цветов.

## Числа и цвета

<Story of={Stories.NumbersAndColors} />

Примеры отображения разных чисел для каждого цвета бейджа.

## Кастомизация

<Story of={Stories.CustomStyles} />

Бейдж можно кастомизировать с помощью пользовательских стилей.

## Свойства компонента

<Controls />

## Использование в коде

### Базовый пример

<Source
  code={`
<me-badge [value]="5" color="default"></me-badge>
`} />

### С кастомными стилями

<Source
  code={`
<me-badge
  [value]="42"
  color="success"
  size="24"
  [customStyle]="{
    border: '2px solid var(--Controls-Content-In-Controls-Accent-Default)'
  }"
></me-badge>
`} />

### Все свойства

<Source
  code={`
<me-badge
  [value]="100"           // Числовое значение
  size="24"               // '20' | '24'
  color="success"         // 'default' | 'secondary' | 'success' | 'attention' | 'error'
  [customStyle]="{...}"   // Пользовательские CSS-стили
></me-badge>
`} />
